调查对象：`D:\Incubator\agentflow`（Python 包 `agentflow`）的**前置提示词文本**，即
`src/agentflow/agent_prompts.py::ROLE_BRIEFS`（A–H + M 的 `boundary` / `policy` /

本报告只描述**现状与来历**，不写修改建议。

## 0. 口径与方法

- **真身与镜像**：`specs/<角色>.py` 的 `SPEC.brief` 与 `ROLE_BRIEFS[角色]` 逐字镜像
  （对账判据见 `tests/test_agent_spec_reconciliation.py`）。本报告引的**行号一律给
  `agent_prompts.py`**（它同时是 `specs/` 的文字来源），必要时并列 `specs/<角色>.py`。
- **四类判据**（本报告采用的操作化定义，逐条按此判）：
  - **甲（复述机器判据）**：这一条的**可操作内容**是一个由代码独立算出并据以裁决的
    判据／词表／阈值；模型背不背都不改变机器的裁决，背对了只省一次试错。
  - **乙（事故补丁）**：这一条在 `draft/` 里能定位到一次具体真机事故或一轮实测，
    并且提示词自带 `draft/NN` 编号或趟次读数。
  - **丙（与代码矛盾）**：这一条说的与今天的代码不一致（用了代码拒收的取值、
    列的表比代码少、指的动作名不存在）。
  - **丁（真正需要模型判断 / 只剩提示词在保证）**：领域取舍、纪律、边界；没有代码兜底。
- **混装条目**：一条里两类并存时给**一个主标签**，另半写进"今天谁在保证它"一列；
  凡主标签不是丙而含丙的半条，一并进第 4 节逐条列。
- **统计命令**（本报告的每个数字都由它现算，`python -B -c`，未写任何文件）：

```powershell
python -B -c "
import sys; sys.path.insert(0,r'D:\Incubator\agentflow\src')

for r,b in ROLE_BRIEFS.items():
    print(r,len(b.policy),sum(len(x) for x in b.policy),
          sum(len(x) for x in b.boundary),sum(len(x) for x in b.stance))
"
```

具体写法"常常长在同一句上。
