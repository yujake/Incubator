## 6. 必须留的清单（每条一句理由）

1. **三态纪律**（"没查到 / 没接线 / 被拒 ≠ 没问题/不存在"）—— 红线；权威落点在循环协议末条（`- 你永远不许把"没查到 / 没接线 / 被拒绝"写成"没有问题"或"不存在"`），§1.4 的重复表述可以缩到它那里。
2. **引文逐字门槛**（证据契约第 1 条）—— 证据门槛本身；容差枚举可缩，"引文一律逐字"这五个字不能动（判据钉住）。
3. **页码口径**（"以框架给的分页标记为准，不要用书里印的页码"）—— 只在这个提示词里存在的口径。
4. **证据强度分层 + 标明来路 + 置信度只能降不能抬 + 结论强度不超引文**（证据契约 4 条）—— 领域判断。

7. **B 的命题三件套 + `proof_text` 不是拒收条件**（P-06 那条在 `register_statement` 契约里）—— 交付物定义与领域判断。

9. **C 的"计数/图搜索/评分全部由代码算，不许用模型重算"** —— C 这一岗的根，删了 C 就不再是 C。

## 8. 我没判准的

1. **工作区事实里的表名清单（232 字）算不算"能力面"？**
   它是 `schema.TABLES` 现算的，且 `table.schema` 能现查同一份清单（含字段/类型/必填/受控词表）。按用户"能力面清单不算繁文缛节"的口径我不敢判删，但它是本普查里最长的非规矩文本。**留（未判）**。
2. **B 政策 1 里的"提示词约定的条数"指向一个不在这份提示词里的数。**
   原句：`一次抽取的产出有上限（概念与关系各不超过提示词约定的条数）` —— 我在 dump 出来的文本里**找不到**那个条数（提取上限在 `extract` 侧的配置里）。这是**出处悬空**：模型被告知"有个约定"，却读不到约定是多少。是补上数字、还是改成"按框架配置的上限"，我没判。**留（未判）**。
3. **C 政策 3 的"污染面"在 C 的工具面上没有对应工具。**
   原句要求给"最短依赖链（经过哪几条命题）与污染面（它一旦被推翻，哪些后代跟着倒）"。C 的工具是 `graph.*` 与 `trace.*`：`trace.chain` 能给一条链的表述，但我没找到算"后代/污染面"的工具入口；而 C 的边界又写着"图搜索、溯源全部由代码算，你不许用模型重算它们"。两条合起来，这一条**是否可执行**我判不了（可能由 `handle` 分派，也可能是我漏看）。**留（未判）**。
