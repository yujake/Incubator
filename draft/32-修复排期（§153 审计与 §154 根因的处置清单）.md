### F4 · 每个智能体一个"能力内请求"（验收，替代门测试）

| 角色 | 派什么 | 观察什么（异常判据） |
|---|---|---|
| A | 检索一个新主题（真实网络） | 落盘/`status` 是否如实；空目录还出现吗；`no_pdf_url` vs `content_mismatch` 分得清吗 |
| B | 处理若干文献 → 概念/关系/逐字引文 | `quote_verified` 三态；HTML 落地页会不会被当论文抽（R-50 的正控） |
| C | 对关系集做结构分析（hottest/cold/gaps） | 三态输出、空集时是否说"没数据"而不是"没有" |
| D | 登记一条猜想并评估 | 状态机拒收、跨对象存在性 |
| E | 跑一个数值实验 + 一个 formal | `evidence_kind` 推导、原始输出落盘、formal 的参数守卫 |
| F | 立项 + `step` 到终态 | 终态是否 `resolved`/`stalled`（含 `best_partial`）；拒绝是否落 `refused` |
| G | 建一份短稿件 + `revise` | 引用存在性、渲染、`content_sha256` |
| H | 审那份稿件 → 签名 → 复审 | `coverage` 如实、签名钉修订哈希、拒绝码（R-46 的正控） |
| M | 用编排面跑一轮（`state`/`ledger`/`stop`/`resume_brief`） | 台账可重建决策序列；停止无僵尸、有简报 |

判定口径：**任何一格出现"把没说清的说成说清了"（拒绝→崩溃、没查→没有、HTML→全文、ok→有产出）
就是异常，继续修**。逐格读数落 `draft/28`。
