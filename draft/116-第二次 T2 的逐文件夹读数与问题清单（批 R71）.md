## §3 本轮已修（三件 + 各一条判据）

### 3.1 锚的格式不对 ⇒ `unknown`（不是 `drifted`）

`renderanchor.check_package`：表哈希位数与框架现算不一致 ⇒ 该维 `unknown` + 点名理由；
锚的 `files` 键是项目相对（`out/paper/main.tex`）⇒ 该维 `unknown`（不再吐三条假的
"锚里有、盘上没了/盘上有的锚里没有"）。漂移行还把两侧位数一并打出来，避免"截断后看起来一样"。

真机复算：对 `projects/p6t2-research-20261012b` 跑修好的判据 ——
`verdict=unknown`、`dimensions={tables:unknown, files:unknown, receipt:unknown}`、
**`drift=[]`**，理由逐条："表 documents：锚里的 sha256 是 12 位，框架现算的是 64 位 ⇒
这份锚不是框架写的（或被截断过）⇒ 这一维判不了（不是「漂了」）"。
判据 `tests/test_renderanchor.py::test_a_hand_made_anchor_is_unknown_not_drifted`
（含反负控：按框架口径重写锚 ⇒ 回到 `consistent`）。

### 3.2 自造免责声明不再过关

`claimanatomy` 新增第 5 族 code **`uncontrolled_disclaimer`**：`cross_check` /
`proof_review` 的 `disclaimer` 写了但**不等于受控那一句**（含"拿错档的声明"）⇒ error。
判据 `tests/test_lean_switch.py::test_a_self_written_disclaimer_does_not_pass`
（受控两句干净、换档/近义/多一个句号都报，且复用的是 `doc_tools` 里那两个常量）。

### 3.3 引一条否证当支撑会被拦下

`doc_tools.check_proofs` 新增第 5 条判据：断言引用的 `exp:` 若 `result="refutes"`，
该断言必须是否定型里"已证否"那一档（`is_negative` + `negation_kind="disproved"`），
否则报 `claim_cites_a_refuting_experiment`。判据
`tests/test_d1_proof_evidence_anchor.py::test_a_claim_may_not_cite_a_refuting_experiment_as_support`
（负控：否定型引它是对的）。写夹具时还被 schema 自己拦了两次（`refutes` 必须给
`counterexample`、且 `negation_kind` 必须是 `disproved`）——那两条**本来就在**，记一笔。

### 3.4 顺带修掉的两个（上一轮同一天发现）
