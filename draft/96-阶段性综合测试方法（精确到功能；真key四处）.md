## §0 三层：每层能证明什么，不能证明什么

| 层 | 装置 | 能证明 | **不能**证明 |
|---|---|---|---|
| **L1 单测** | `pytest`（假网关 / 最小替身） | 代码按判据走；红/绿成对（负控 + 反真空） | 链路在真数据结构上通不通；模型会不用它 |
| **L2 综合** | **真** `Conductor` + **真** `tasks`/`out/roster`/`handoffs` + 假网关（照剧本回形状） | 一条完整链路在真盘上跑通（造树、派活、渲染、退役、面切割、并发） | 模型**会不会**表达这套语法（形状、本地名、brief、补一句给父的话） |
| **L3 真 key** | `agentflow --root <ws> run-agent …`（真模型） | 模型能表达/理解这套语法；提示词读得懂进得去 | 长跑稳定性（那是 M5 的 T1–T5 重跑） |

**三态**：没有 key / `doctor --probe` 不通 ⇒ L3 记 **`not_run`**（并在当批提交信息里写"L3 未跑"）；
**`not_run` 不是通过**。

## §1 公共装置（一次写好，各阶段复用）

1. **工作区**：`temp/it-<stage>/ws`（`agentflow --root <ws> init`）。
   **绝不在 `agentflow/projects/` 里跑**——那 61 个目录是只读证据（`draft/94` §0 的复现口径）。
2. **造树夹具**：`_tree(role)`（`tests/test_children_and_parent_are_visible.py` 已有）——
   顶层行 → 我的实例行 → 我的两个孩子；综合测试一律用它造真树，不手写 dict 落盘。
3. **假网关**：`_Gate` / `ScriptedGateway`（照剧本回形状或文本，记录 `prompts` / `systems`）。
4. **录制回放语料（零成本，替代一部分真 key）**：真机的 1562 行手稿 + 579 条留言 +
   2276 行 `tasks`（`draft/89`/`draft/94` 的读数）拿去喂**洗格式**与**译码**，
   比"编一个错名"更接近真机（真机里错名/缺键长什么样，是录制语料说了算）。
5. **断言三件套**（每条综合判据都要落到其中至少两处）：
   ① 盘上读数（`tasks` / `out/roster/*` / `out/secretary/*` / `handoffs`）；
   ② **提示词**（`gate.systems[-1]`：模型看见了什么）；③ 返回值 / 收据（`receipt` / `action` / `why`）。
6. **负控必须在 L2 也有一条**（只靠 L1 的负控证明不了"链路层拒绝"）。
7. **每阶段收尾一律跑**：目标 `pytest` 集 + `python -B scripts/lint_rules.py`（比基线）+
   金标红清单（`--with-pytest` 太重，只在 M5 跑一次全量门）。

## §3 真 key 只跑这四处（必要性 + 命令 + 预算 + 断言）

**前置**：`agentflow doctor` 与 `agentflow doctor --probe`（T3=分级已裁）先跑；
`--probe` 不通 ⇒ 四处全记 `not_run`。

| 代号 | 必要性（为什么假网关不行） | 命令（工作区在 `temp/it-*`） | 断言 | 预算 |
|---|---|---|---|---|
| **K1** | 模型**会不会**用新语法：`{"retire":{"name":"D1"}}` 与 `brief` 必填、`reuse` 用本地名 | `run-agent M --task "派一个 D 的 run_once 做 X（brief 一句），等它交差后看活跃名册并把它退役" --drive D.run_once --max-steps 12 --budget-usd 0.15` | 名册 +1 且**有那句 brief**；退役事件一条；**M 的提示词里不出现 `t-00xx`**（只有本地名/角色） | ≤$0.15 |
| **K2** | 上行消息真机 **0 条**（`draft/94` §5）⇒ "模型会不会给父发、用不用父的本地名"没有任何证据 | 同上的一次跑里追加任务句："D 干完活**给你（父）发一条**再说收工" | `agent_message` 有一条 `from`=D 的本地名、`to_name`=父的本地名（顶层写"（顶层）"）；父**自己** ack | 与 K1 同趟（不加钱） |
| **K3** | "看名册 → 决定退役"是**模型的决策**（活跃时必须先报最近报告）：stub 只能证明代码分支，证明不了提示词教得会 | `run-agent M --task "D1 还在跑时你试着退役它，看它最近报了什么；等它停下再退" --drive D.run_once --max-steps 12 --budget-usd 0.15` | 第一次 `action="reported"` 且回报里是**最近报告原文**；第二次 `retired` | ≤$0.15 |
| **K4** | 广播的**级联自愿性**（子只发给自己的子；M 的全树靠逐层向下）是行为问题 | 同上跑里追加："让你名下的子代理各自决定要不要向它的子广播"（三层树，`--subagents` 只驱动必要的动作） | 广播只到自己的子；子代理**没有**发给兄弟；ack 三格读数齐全 | ≤$0.15（可与 K1/K3 合并成一趟，见 §4） |

**四处合起来的实际开销**：**2 趟真跑**（K1+K2 合一趟，K3+K4 合一趟）× $0.15 ≈ **≤$0.3**；
每趟必须落：`run-manifest` + `sid` + 账本读数（`usage_ledger` 汇总）+ 这一趟的 `tasks`/名册/对照表摘要，
写进 `draft/94` 的"真 key 跑读数"一节（新开 §9）。

**K 系列不许做的事**：不许在 `projects/` 里跑；不许把 `not_run` 写成通过；
不许用 `--budget-usd` 之外的方式省钱（比如偷偷把 `--max-steps` 降到 3 让模型没机会退役）；
不许把 K 的读数当 M5（长跑）的替代。

## §4 省钱与合并（把四处压成两趟）

```text
趟 1（K1+K2）：M 造 D1（brief 必填）→ D1 干完 → D1 给父发一条 → M 读名册 → M 退役 D1
趟 2（K3+K4）：M 在 D1 还在跑时试着退役（拿到最近报告）→ 等它停 → 退役 → 让子代理自行决定是否向下广播
```
两趟都要求 `--budget-usd 0.15`、`--max-steps 12`、`--wall-clock-sec 600`；
**任何一趟撞预算 ⇒ 如实记 `budget_hit`**（不是通过，也不是失败：它是一次"没跑完"的读数）。
