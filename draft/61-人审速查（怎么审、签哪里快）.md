## §0 三条命令 + 批准流程（照 `AGENTS.md` 的规矩）

```powershell
cd D:\Incubator\agentflow
# ① 现状（只读）：27 条命中 + 清单两处一致 + 台账对账 + 新旧 sha/reviewers
python -B scripts/noai_gate.py --git --json          # verdict=requires_human / required_approvals=2 / exit 1
python -B scripts/noai_gate.py --check-consistency   # 0 = `.noai-paths` 与 AGENTS.md 逐条一致
python -B scripts/noai_gate.py --check-ledger
python -B ..\temp\_review_queue.py                   # 每条：台账 sha / 盘上 sha / reviewers 数 / 状态
# ② 刷新登记（**不是批准**；`--baseline` 永远不写 reviewers）
python -B scripts/noai_gate.py --baseline --paths <路径> --note "<这一段改了什么>"
# ③ 两名 reviewer 各签一次（**AI 不得运行 --approve**；批准绑在 sha256 上）
python -B scripts/noai_gate.py --approve <路径> --reviewer "<人名>" --scope "<符号或行区间>" --verdict "<结论>"
```

**三个坑**：① **批准绑 sha** ⇒ 表里 20 条"已过期"，必须**先 `--baseline` 再 `--approve`**，否则签的是旧字节；
② `--scope` **不许写"看过了"**（要具体到符号/行区间）；③ 报备清单**按文件去重**（同一文件会以 `agentflow/src/…` 与 `src/…` 两种形态出现），且 `temp/tools/coverage_zero_test.py` 是**旧实现快照副本的假阳性，不用审**。
