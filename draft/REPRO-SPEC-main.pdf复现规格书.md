## 1. 论文核心内容摘要（≤400 字）

论文构造一对无限、局部有限、顶点传递、周期秩同为 m−1、度数同为 m 的周期图 K(m) 与 S̃_m，并证明 m = 4, 5 时二者**谱相同而不构**，故"谱（作为集合）不能决定周期图"。

- K(m)：V_K = {x ∈ Z^m : Σx_i ∈ {0,1}}，边 {x, x ± e_i}（Def. 1.1, p.1）。
- S̃_m：W_a(Ã_{m−1}) = Q^∨ ⋊ S_m 关于 {s_0, …, s_{m−1}} 的 Cayley 图（腔图）（Def. 1.2, p.2）。
- **Spec K(m) = [−m, m]** 对一切 m ≥ 3，论文自证（Thm. 1.3, §3）。
- **Spec S̃_m = [−m, m]** 仅 3 ≤ m ≤ 5，且引自 [6, Thm. 6.5]，未重证（Rem. 1.6）。
- **girth K(m) = 6**（m ≥ 3）；girth S̃_3 = 6，girth S̃_m = 4（m ≥ 4）（Thm. 1.4, §4）。
- 于是 m = 4, 5 时同度、同秩、同谱而围长不同 ⟹ 不同构（Thm. 1.5）。

**范围**：K(m) 的两条结论对一切 m ≥ 3；"余谱不同构"仅 m ∈ {4,5}；m ≥ 6 时 Spec S̃_m 的等式为公开问题（§6）。论文强调数值不作证明，且不声称"没有谱不变量能区分"（更细的谱测度/态密度是否区分未决）。

## 2. 精确定义（逐字/忠实转述，标注页码与节号）

> 记号约定：抽取文本把 S̃_m 写作 `eSm`（PDF 中的 `\widetilde S_m`），把 Q^∨ 写作 `Q∨`。下文统一写 `S̃_m`、`Q^∨`。

**(D1) V_K 与 K(m)** —— p.1, §1.1, eq. (1) 与 Def. 1.1
固定 m ≥ 3，e_1, …, e_m 为 Z^m 的标准基。

    V_K := { x ∈ Z^m : Σ_{i=1}^{m} x_i ∈ {0,1} }            ……(1)
    K(m) 是以 V_K 为顶点集、x 与 y 相邻当且仅当 y = x ± e_i（某个 i）的图。

论文正文原话：*"K(m) is the graph with vertex set V_K in which x and y are adjacent when y = x ± e_i for some i."*

**(D2) coroot lattice Q^∨** —— p.2, Def. 1.2；p.4, §3 开头

    Q^∨ = { x ∈ Z^m : Σ_i x_i = 0 } ≅ Z^{m−1}          （A_{m−1} 的余根格）
    在 §3 中被识别为 Z^{m−1}：x ↦ (x_1, …, x_{m−1})（末坐标由 Σx_i = 0 决定）
    角色 χ ∈ T^{m−1} 是 Q^∨ 的特征标，z_i := χ(e_i)。

**作用**：Q^∨ 通过平移作用于 V_K（p.2, §1.1 末尾；p.3, Lemma 2.2 证明），保持 Σ_i x_i，因而保持 V_K 与两个层级 {Σ=0}、{Σ=1}。

**(D3) 仿射 Weyl 群 W_a(Ã_{m-1})** —— p.2, Def. 1.2

    W_a(Ã_{m−1}) = Q^∨ ⋊ S_m ，作用于 Z^m ： x ↦ w(x) + λ ，w ∈ S_m, λ ∈ Q^∨。

**群律（论文 §5, p.7 明示）**：

    (w, λ)(v, µ) = ( w v ,  λ + w(µ) )

【推断】该群律的**方向由"仿射映射的复合"唯一确定**：先作 x ↦ v(x)+µ 再作 x ↦ w(x)+λ 得 x ↦ wv(x) + w(µ) + λ，故为上式。其中 `w(µ)` 必须与仿射作用 x ↦ w(x) 中的 S_m 作用**用同一约定**（这是最容易写错的地方，见 §7 R1）。自洽的两种写法（二者只差 w ↔ w^{−1}）：
- 约定 A：`(pq)(i) = p(q(i))` 且 `(w·x)_i = x_{w^{−1}(i)}`；
- 约定 B：`(pq)(i) = q(p(i))` 且 `(w·x)_i = x_{w(i)}`。
两者都使群律满足结合律；**混用（例如 `(pq)=p∘q` 配 `(w·x)_i = x_{w(i)}`）会使群律不满足结合律**（【实测】见 §8 表 A4）。

**(D4) 简单反射与仿射反射** —— p.2, Def. 1.2

    论文原话：*"Let s_1, …, s_{m−1} be the simple reflections of the finite Weyl group and
    s_0 = s_θ [抽取为 "s_θ, θ"] the affine reflection, where θ = e_1 − e_m and s_θ is the
    transposition of coordinates 1 and m."*

- 【推断】论文以"θ = e_1 − e_m 时 s_θ 是坐标 1 与 m 的对换"给出**线性部分**的约定；由此按 α_i = e_i − e_{i+1} 的标准简单系，**s_i = 坐标 i 与 i+1 的对换**（i = 1, …, m−1）。论文**未给出** s_i 的显式坐标形式。
- 【抽取歧义】PDF 中 s_0 的定义在抽取文本里残缺为 `s0 = sθ, θ`。最可能的原文是"仿射反射 s_{θ,k}"（即跨越超平面 ⟨x, θ⟩ = k 的反射）一类记号；**论文文本无法唯一确定其平移部分**。
- 【推断】取标准约定（基本 alcove 的壁 ⟨x, θ⟩ = 1）：

      s_0(x) = x − (⟨x, θ⟩ − 1) θ = w_0(x) + θ ，即
      s_0 = (w_0, θ) ∈ W_a ，w_0 = 坐标 1 与 m 的对换 ，θ = e_1 − e_m

  该元素满足 s_0² = 1（【实测】确认，见 §8 表 A4）。**符号 θ → −θ 不影响图**：映射 ψ(w, λ) = (w, −λ) 是 W_a 的自同构，逐点固定 (s_i, 0) 并把 (w_0, θ) 送到 (w_0, −θ)，故两种符号给出同构的 Cayley 图（【推断】+【实测】：两种符号下 m=3 围长均为 6）。
  **但平移部分不能丢**：若误取 s_0 = (w_0, 0)（纯有限 Weyl 元素），则 m = 3 时算出的围长为 4，与定理 1.4 矛盾（【实测】见 §8 表 A5）——这是一个可判定的自检点。

**(D5) 腔图 S̃_m** —— p.2, Def. 1.2

    S̃_m := Cay( W_a , {s_0, s_1, …, s_{m−1}} ) ，即"两腔共享一面墙则相邻"的图。

论文未说明是左 Cayley 图还是右 Cayley 图；【推断】因生成元全部是对合（S = S^{−1}），左/右 Cayley 图经 g ↦ g^{−1} 同构，**围长不受影响**（【实测】左右乘结果一致）。

**(D6) periodic graph 与 periodic rank** —— p.3, Def. 2.1
设 X 是局部有限、连通、**简单**图，Γ ≤ Aut(X) 是**自由**作用于 V(X)、轨道有限的自由阿贝尔群。称 X 为 Γ-周期图，称 rank Γ 为其 **periodic rank**。

**(D7) Floquet/Bloch 分解与周期图的谱** —— p.4, Def. 2.4 与 eq. (2)
设 X 为 Γ-周期图，X/Γ（有限商，**multigraph**，称 cell）有 d = rank Γ 个方向的周期。对 χ ∈ Γ̂ = T^d，**Floquet 矩阵** A_χ 以 V(X/Γ) 为指标集，"从 x 的类到 y 的类的元素 = Σ χ(λ)，求和遍历所有 λ 及所有满足 x ~ y + λ 且诱导该 类–类 转移的邻接"。定义

    Spec X := ⋃_{χ ∈ T^d} Spec A_χ                              ……(2)

Prop. 2.5（p.4，引 [3, 2]）断言 (2) 与 ℓ²(V(X)) 上邻接算子 A 的谱一致。

**(D8) K(m) 的 cell 与 Floquet 矩阵** —— p.4–5, Lemma 3.1, eq. (3)(4)(5)(6)
对 a, b ∈ Z^{m−1}：

    A_a := (a_1, …, a_{m−1}, −Σ_{i<m} a_i) ∈ V_K      (Σ_i x_i = 0)     ……(3)
    B_b := (b_1, …, b_{m−1}, 1 − Σ_{i<m} b_i) ∈ V_K    (Σ_i x_i = 1)     ……(4)

(i) {A_a} 与 {B_b} 恰是 V_K 的两个 Q^∨-轨道，各与 Z^{m−1} 双射（通过 x ↦ (x_1,…,x_{m−1})）。
(ii) K(m) 的边恰为

    A_a ~ B_{a+e_i} (1 ≤ i ≤ m−1),   A_a ~ B_a,
    B_b ~ A_{b−e_i} (1 ≤ i ≤ m−1),   B_b ~ A_b                        ……(5)

(iii) 因此 cell V_K/Q^∨ 是**两顶点、m 条平行边**的 multigraph，电压为 0, e_1, …, e_{m−1} ∈ Q^∨，且

    A_χ = [ 0   S(χ) ;  S(χ)  0 ] ，  S(χ) := 1 + z_1 + ⋯ + z_{m−1} ，z_i := χ(e_i)   ……(6)
    Spec A_χ = { ±|S(χ)| }

【推断/注意】式 (6) 中两个非对角元在论文里都写作 S(χ)；论文证明正文写明"**反向为共轭**"（*"and the conjugate in the opposite direction"*）。故数值实现应取 A_χ = [[0, S],[conj(S), 0]]（厄米），谱仍为 {±|S|}。

**(D9) 周期格的选取与 Λ = mQ^∨** —— p.4, Remark 2.3
- 能作为周期格的格必须保持 V_K，这已强制它落在 Q^∨ 内；**Q^∨ 是 K(m) 的极大周期格**，其他合法选取都是 Q^∨ 的有限指数子格。
- **Λ := mQ^∨ = {m v : Σ_i v_i = 0}**，在 Q^∨ 中指数为 **m^{m−1}**，给出顶点数为 **2m^{m−1}** 的 cell：类的指标为 (x_1, …, x_{m−1}) mod m 以及 Σ_i x_i ∈ {0,1}；"a Floquet matrix of that size"。论文说这"合法但更难"，故正文用极大格 Q^∨（cell 只有两个顶点）。

**(D10) bipartition** —— p.5, Remark 3.2 与 Remark 3.4
每条边连接 A-顶点与 B-顶点；K(m) 二分，两部分为 {Σ_i x_i = 0} = {A_a} 与 {Σ_i x_i = 1} = {B_b}。

**(D11) 论文未给出的记号**：论文**未给出** girth 的形式定义（按标准理解为最短圈长，且 Example 1.8, p.2 以"六点互异、相邻差为带符号标准基向量、坐标和属 {0,1}"的方式示例了一个 6-圈）；**未给出** S̃_m 的 cell/电压数据（§6, p.8 只说 cell 有 m! 个顶点）；**未给出** §5 中网格分辨率、箱半径等具体参数。

## 4. 可计算验证清单（规格书核心）

### 4.0 通用约定、容差与"通过"的定义

- **数值环境**：任意双精度环境（本规格书基线用 Python 3.11 + NumPy 2.4；算法不依赖特定库）。所有矩阵元素都由单位复数精确构造，误差只来自浮点。
- **容差**：矩阵元素厄米性 `‖A − Aᴴ‖_max ≤ 1e-12`；直接构造（2×2、Λ-cell、腔图 cell）的特征值比较 `atol = 1e-9`；含三角函数的量（\|S\|、网格）用 `atol = 1e-9`。**"谱填满区间"这类连续命题一律不采用浮点"接近即通过"**，而采用 §4.9 的可判定离散判据。
- **结构性判据优先**：凡有精确整数/代数答案的量（顶点数、度数、轨道数、围长、显式见证处的 \|S\|）都用精确判据（整数相等或 `≤1e-9` 的代数点求值），不用"看起来像"。
- **反例搜索优先于"通过"**：`proof-only` 与 `quoted` 条目只做反例搜索，报告"未发现反例（在给定范围内）"，不得报告"验证成立"。

       提升角为 ((θ_i + k_i)/m)，k_i = 0,…,m−1

### 4.3 C03 — girth S̃_m（m = 3 为 6；m ≥ 4 为 4）

**期望值**：m = 3 → 6；m = 4,5,6 → 4。等价结构性期望：m ≥ 4 时存在一对**不相邻**的 Coxeter 节点（s_1 与 s_3 即可，Ã_{m−1} 的 Coxeter 图是 m-圈），它们交换故 1, s_1, s_1s_3, s_3 是 4-圈；m = 3 时 Ã_2 是三角形，无交换对，且符号特征标使一切闭途径为偶长度 ⟹ 围长 ≥ 6，而 ⟨s_i,s_j⟩ ≅ S_3 的 braid 圈给出 6。

**算法**：见 §5.4 `girth_chamber(m, radius)`（按 Coxeter 表示/词度量建球）。

**判据**
- (P1) m = 3：μ_3 = 6 且 6 ≤ 2·3 = 6 ⟹ 证书成立。【实测】|B_3| = 19，μ_3 = 6。

- (P4) 生成元自检：每个 s_i、s_0 的平方为恒等；braid 关系 (s_i s_{i+1})³ = 1、(s_0 s_1)³ = 1（m ≥ 3）、(s_0 s_{m−1})³ = 1、m_{ij} = 2 的非相邻对交换。这些是**必须**通过的群自检（见 §7 R1/R2）。

### 4.9 连续命题"谱填满 [−m, m]"的可判定离散判据（关键设计）

设 m−1 个角度，网格 `θ_i^{(k)} = 2πk/N`（k = 0..N−1），采样集 `V_N = { ±|S(χ)| : χ ∈ grid }`。**注意 \|S\| 只是 (m−1) 元角度的函数**，因此 2×2 通道的采样代价是 O(N^{m−1})。

- **G1（可证伪的上界）**：`max_{v∈V_N} |v| ≤ m + 1e-9`。任何超出即为反例。
- **G2（端点，精确而非搜索）**：`|S(1)| = m` 精确；`|S(χ_0)| ≤ 1e-12`，其中 χ_0 由 §4.1 的**显式代数见证**构造（不走网格）。若 N 与见证的分母不整除，网格上根本采不到 0 —— 这正是必须用显式见证而非网格搜索的原因。
- **G3（无大间隙，离散可判定）**：把 V_N 排序为 v_1 ≤ … ≤ v_P。由 Lipschitz 估计

      |S(χ) − S(χ′)| ≤ Σ_{i<m}|z_i − z_i′| ≤ (m−1)·(π/N) =: ε

  （每个角度与最近网格点的偏差 ≤ π/N）。判据：`max_k (v_{k+1} − v_k) ≤ 2ε`，且 `v_1 ≤ ε`、`v_P ≥ m − ε`。**含义**：采样点在分辨率 ε 下构成一条"无洞"的区间链；它**证伪**"存在宽度 > 2ε 的谱隙"，但**不证明**像等于 [0,m]。
- **G4（路径扫描）**：取 generic 无理方向 u ∈ R^{m−1}，路径 χ(t) = exp(2πi t u)，t ∈ [0,1]，采 P 点。判据：`max_t |S| ≤ m + 1e-9`，`min_t |S| ≤ 2π(m−1)‖u‖/P + 1e-9`（路径步长给出的界），且相邻采样差 ≤ 同一界。这是 §5 中"连续特征值路径扫过整个区间"的可判定版本。
- **"需要证明的部分"**：区间等式的证明在论文 §3(a)：\|S(T^{m−1})\| 是**连通**集的连续像、含 0 与 m，故等于 [0,m]；再代回 (7) 得 Spec K(m) = [−m,m]。数值**无法**替代这两步（连通性 + 端点），只能作为一致性与反例搜索。**任何报告必须写成"C01 的数值检查通过（G1–G4），证明见论文 §3"，而不是"数值证明了 C01"。**
- **网格选择建议**：由经验标定（【实测】§8 表 A3），取 ε/(m) ≈ 1% 量级需要：m = 3 → N = 48；m = 4 → N = 48；m = 5 → N = 24（实测最大间隙/m = 0.0081）。建议固定 N = 60 并对 m = 5 用 N = 24 或 36 作为预算折中；应报告 maxgap 随 N 的收敛（约 O(1/N)）。

### 4.10 围长的"盒子证书"（把"盒子多大才够"变成可判定命题）

**引理（本规格书给出，用于把经验判据升级为证书）**：设 X 顶点传递、局部有限，B(x_0, r) 为半径 r 的球，μ_r := 球内诱导子图的最小圈长（无圈时记 ∞）。若 **μ_r ≤ 2r**，则 μ_r = girth X。
证明：girth 圈 \mathcal{C}（长度 g）过 x_0（顶点传递保证存在），其上任一顶点到 x_0 的距离 ≤ ⌊g/2⌋，故 \mathcal{C} ⊆ B(x_0, ⌊g/2⌋)。于是 μ_r ≥ g 恒成立；若 μ_r > g 则 r < ⌊g/2⌋ ≤ g/2 < r，矛盾。∎

**实践判据**：对每条围长结论，报告 (r, μ_r) 表并检查 `μ_r ≤ 2r`；只报告"球内最小圈"而不检查 `μ_r ≤ 2r` 是**不可接受**的（那只是上界）。本论文的两个目标值都只需 r ≤ 3：
- K(m)：r = 3，μ_3 = 6 = 2r ✔（【实测】m = 3,4,5）；
- S̃_m：m = 3 时 r = 3，μ_3 = 6 = 2r ✔；m ≥ 4 时 r = 2，μ_2 = 4 = 2r ✔（【实测】m = 4,5）。
**注意**：这里的 r 是**图的度量**（对 S̃_m 是 Coxeter 词度量，即按生成元建 BFS），不是 Z^m 上的坐标范数 —— 用错度量会得到无意义的"球"（见 §7 R8）。
**另一条独立性检查**（可选但推荐）：对 K(m) 直接用穷举法列出原点处长度 ≤ 6 的所有闭途径并筛选"顶点互异"，与球内方法互证：由于 K(m) 顶点传递（C13）且三角形由二分性排除，等价于检查"闭途径长度 ≤ 6 中不存在长度 4 者、存在长度 6 者"。穷举量 ≤ (2m)^6（m = 5 时 ~10⁶，可行）。

### 5.1 `build_K_quotient(m)` —— K(m) 在 Λ = mQ^∨ 下的有限商图

```
输入: m ≥ 3
输出: 顶点表 V, 邻接多重表 E, 校验量

# 1. 顶点：类 = (a, s)，a ∈ (Z_m)^{m-1}，s ∈ {0,1}；共 2·m^{m-1} 个
V = [ (a, s) for a in product(0..m-1, repeat=m-1) for s in (0,1) ]
assert len(V) == 2 * m**(m-1)        # 【论文】Rem 2.3

# 2. 代表元（仅用于电压计算；谱与代表元选择无关）
rep(A_a) = a + (-sum(a),)            # 层级 0，坐标和 0        ……(3)
rep(B_b) = b + ( 1-sum(b),)          # 层级 1，坐标和 1        ……(4)

# 3. 边 + 电压（Λ-商图；对照 (5)）
for a in (Z_m)^{m-1}:
    for j in 1..m-1:                                   # 方向 e_j, j < m
        c_raw = a + e_j ; c = reduce_mod(c_raw, m)
        v     = (c_raw - c) / m  ∈ {0,1}^{m-1}          # 绕回修正
        add_edge (a,0) -- (c,1)  with voltage  v
    c = a                                              # 方向 e_m
    add_edge (a,0) -- (c,1)  with voltage  0
    # 反向边由无向性给出（同一 λ 的相反数 → 共轭权重）
assert 每个顶点度 = m
assert 所有边都跨层级（二分）        # 【论文】Rem 3.2

# 4. 自检
assert |V| == 2*m**(m-1)             # m=3,4,5 → 18,128,1250
assert 度数集 == {m}
assert 商图是简单图（m 个目标类互异）   # 与 cell(Q^∨) 的 m 条平行边对照
assert 对 s ∈ {0,1}: 层级 s 与 Σ rep = s 一致
```

**实现要点**
- 顶点数必须**代数**得到；不要把 V_K 限制在某个坐标盒里再取模（盒子会漏类，见 §4.7 与 §7 R5）。
- 电压 `v ∈ {0,1}^{m-1}` 的方向（+1 还是 −1）取决于代表元的取法；换代表元只做对角酉变换。**同一实现内自洽**即可，谱与围长判据都不受影响，但 §4.1 的提升一致性检查要求电压与 z 的幂次方向一致（实现时应把这一条写成断言）。

### 5.2 `floquet_spectrum_K(m, grid)` —— 双通道 Floquet 谱

```
输入: m, 每角网格点数 N（或显式给定的特征标集合）
输出: 采样谱集合, 各判据结果

# 通道 1：极大格 Q^∨ 的 2×2 cell              ……(6)
for k in product(0..N-1, repeat=m-1):
    theta = 2*pi*k/N ; z_i = exp(i*theta_i) ; S = 1 + sum(z)
    A = [[0, S], [conj(S), 0]] ; lam1 = ±|S|
    record(spectrum_1, lam1)
# 自检：chi = 1 时 A = [[0,m],[m,0]]，极值 ±m（C24）

# 通道 2：Λ = mQ^∨ 的 2m^{m-1} × 2m^{m-1} cell（§5.1 的商图 + 电压）
def A_Lambda(m, theta):
    z_i = exp(2*pi*i*theta_i) ; A = zeros(2*m**(m-1))
    for a in (Z_m)^{m-1}:
        for (c, v) in neighbours_with_voltage(a):        # 见 §5.1 第 3 步
            w = prod_i z_i^{v_i}
            A[ idx(a,0), idx(c,1) ] += w
            A[ idx(c,1), idx(a,0) ] += conj(w)           # 反向 = 共轭
    assert A == A.conj().T
    return A
for k in grid:
    lam2 = eigvalsh(A_Lambda(m, 2*pi*k/N))
    record(spectrum_2, lam2)

# 通道 3（把两通道锁死的可判定恒等式）
for k in grid:
    lifts = { (theta + k')/m : k' ∈ (Z_m)^{m-1} }        # 注意除以 m！
    pred  = [ ±|1 + sum(exp(2*pi*i*lift))| for lift in lifts ]
    assert sorted(eigvalsh(A_Lambda(m, theta))) ≈ sorted(pred)   # atol 1e-9

# 判据 G1..G4（§4.9）
G1: max |lam| ≤ m + 1e-9
G2: |S(1)| == m ; |S(explicit_witness(m))| ≤ 1e-12       # 精确代数点，非网格搜索
G3: sorted(V_N) 的最大相邻间隙 ≤ 2*eps_Lip, eps_Lip = (m-1)*pi/N, 且 v_1 ≤ eps, v_P ≥ m-eps
G4: 沿 chi(t)=exp(2*pi*i*t*u) 的路径（u 取无理方向）检查上界与相邻差
```

**实现要点与陷阱**
- `explicit_witness(m)`：m = 3 → (e^{2πi/3}, e^{4πi/3})；m ≥ 4 → z_1 = −1 且 z_2..z_{m−1} = 全部 (m−2) 次单位根。用精确复数直接求值，**不要**依赖网格是否含该点。
- 通道 3 的提升角是 `(θ + k)/m`。写成 `θ + k/m` 会产生 O(0.1) 偏差（【实测】见 §8 表 A2），且不会破坏"包含 ±m"的检查，因此**必须**显式实现这条恒等式检查。
- A_χ 的两个非对角元必须取共轭关系（论文证明原文："the conjugate in the opposite direction"）。
- 采样预算：通道 2 的每个特征标要对角化 2m^{m−1} 阶矩阵（m = 5 时 1250 阶），因此通道 2 只需少量随机/低分辨特征标 + 若干条路径；通道 1 与通道 3 才是"面"上的检查。

### 5.3 `girth_K(m, radius)` —— K(m) 的有限盒围长（带证书）

```
输入: m ≥ 3, r_max
输出: (r, mu_r) 表, 证书结论, 稳定性结论

def ball_K(m, r):                       # 半径 r 的顶点球（图度量 = 步数）
    B = {origin=(0,...,0)} ; frontier = {origin}
    dist = {origin: 0}
    while frontier 非空的 dist < r: 用 (5) 的邻接规则扩张一圈
    return 诱导子图 G[B]                  # 顶点集 B，边 = K(m) 中两端都在 B 的边

def girth_of(G):                        # 对每个顶点 BFS，统计非树边 → 最小环长
    与标准"有限图 girth"算法相同（O(|B|·|E|)），无圈返回 ∞

for r in 2..r_max:
    (B, G) = ball_K(m, r) ; mu[r] = girth_of(G) ; report(|B|, mu[r])
    if mu[r] ≤ 2*r: 证书 = (girth K(m) == mu[r]) ; break     # §4.10 引理
    else: 继续增大 r（本图不会用到）
# 独立性检查（可选）：穷举原点处长度 ≤ 6 的闭途径，输出其中顶点互异者的最小长度
# 交叉检查：二分性 → 无奇圈；r 与 r+1 的 mu 一致
```

**盒子多大才够（可判定的回答）**：不需要经验猜测 —— 用 §4.10 的引理：一旦某个 r 满足 μ_r ≤ 2r，答案即为 girth。对本图 r = 3 就够（μ_3 = 6 = 2r）。若采用引理之外的做法（例如只看"球内最小圈"），则**必须**报告 (r, μ_r) 序列并说明为何认为稳定，且必须承认那只是上界。
【实测】K(3)/K(4)/K(5)：r = 2 → 无圈；r = 3 → μ = 6（= 2r，证书成立）；r = 4 → μ = 6。

### 5.4 `girth_chamber(m, radius)` —— 腔图 S̃_m 的球内围长

```
输入: m ≥ 3, r_max（论文 §5 用 6；本规格书判据只需 2–3）
输出: (r, |B_r|, mu_r) 表, 证书结论

# 群元素表示：g = (w, λ)，w ∈ S_m（像元组），λ ∈ Z^m 且 sum(λ) = 0
def mul(a, b):                          # (w,λ)(v,µ) = (wv, λ + w(µ))      【论文 §5】
    (w,lam) = a ; (v,mu) = b
    return ( pmul(w,v) , lam + act(w, mu) )       # 约定见 §2 (D3)
def pmul(p,q): return tuple(q[p[i]] for i)        # 约定 B
def act(w,x):  return tuple(x[w[i]] for i)        # 与 pmul 配套；混用则群律不结合

gens = [ (transposition(i,i+1), 0) for i in 1..m-1 ] + [ (w0, θ) ]   # w0 = (1 m), θ = e_1 − e_m

# --- 群自检（必须全部通过）---
assert 每个 g ∈ gens 满足 mul(g,g) == identity
assert 结合律：随机 300 组 (a,b,c)，mul(mul(a,b),c) == mul(a,mul(b,c))
assert 逆元：(w,λ)^{-1} = (w^{-1}, −w^{-1}(λ))
assert 每个 g ∈ gens 的阶与 Coxeter 数据一致（braid 关系 (s_i s_{i+1})³ = 1，(s_0 s_1)³ = 1 等）

def ball_chamber(m, r):                 # 词度量球（Cayley 图 BFS），左乘或右乘均可
    B = {identity} ; dist = {identity: 0} ; frontier = B
    while frontier 非空: 对每个 g、每个 s ∈ gens 扩张 h = mul(g,s)（或 mul(s,g)）
    return 诱导子图 G[B]                # 边 = 生成元连接且两端在 B 内

for r in 2..r_max:
    (B, G) = ball_chamber(m, r) ; mu[r] = girth_of(G) ; report(|B|, mu[r])
    if mu[r] ≤ 2*r: 证书 = (girth S̃_m == mu[r]) ; break
# 附加验证：m=3 的 braid 6-圈；m≥4 的 1, s_1, s_1 s_3, s_3 四点圈
```

**实现要点与陷阱**
- **度量**：球必须按生成元步数（Coxeter 词度量）构造，不是按 λ 的欧氏/ℓ¹ 范数。
- **左/右乘**：因 S = S^{−1}，二者给出同构图（g ↦ g^{−1}），围长不变。【实测】一致。
- **s_0 的平移部分不可省**（见 §2 (D4)、§7 R2）。
- 【实测】词度量球规模（约定 B，m = 3/4/5）：|B_2| = 10/15/21，|B_3| = 19/35/56，|B_6| = 64/195/456。半径 6 的球很小，论文 §5 的做法没有计算量问题。
- 若实现的群律不满足结合律，球规模会明显变化（【实测】错误约定下 m = 3 的 |B_6| = 114 而非 64），围长却**仍可能**正确 —— 因此**必须**显式跑结合律检查，不能靠围长结果反推群律正确。

**(a) 纯引文、我们无法独立证明的**
