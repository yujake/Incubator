# 攻坚 000000 · S1 中间结论（P1）

命题 P1（cross_check 级，未形式化）。设 k 为域，V 为 k-向量空间且 dim_k V = ∞。令 g = L(V) 为 V 上的自由 k-Lie 代数（基取 {x_i : i>=1} 时即 F_inf）。则 U(g) 不是左 Noetherian 环。

证明（4 步，每步给出依据）：
1. U(L(V)) = T(V)（张量代数）。依据：PBW 定理 —— 自由 Lie 代数 L(V) 的泛包络代数以 V 上所有字的集合为 k-基，乘法即拼接；对无限维 V 取有限维子空间的直接极限，PBW 单项式仍 k-线性无关且张成。
2. 增广映射 eps: T(V) -> k，eps|_V = 0；A_+ = ker eps = (+)_{n>=1} V^{(x)n}（全部正次数分支）。它是 T(V) 的双边理想，当然也是左理想。
3. A_+ / A_+^2 = V^{(x)1} = V：按 Z-分次，A_+ 的第 n 次分支是 V^{(x)n}（n>=1），A_+^2 = (+)_{n>=2} V^{(x)n}，商恰剩 n=1 这一支，即 V；故 dim_k (A_+/A_+^2) = dim_k V = inf。
4. 反设 A_+ 由有限个元素 f_1,...,f_r 左生成：A_+ = sum_{j=1..r} T(V) f_j。对每个 j 与任意 g in T(V)，有 g f_j = eps(g) f_j (mod A_+^2)（因 g = eps(g)*1 + (g - eps(g)*1)，而 g - eps(g)*1 in A_+）。于是 A_+/A_+^2 由 {f_j mod A_+^2} 的 k-张成，维数 <= r < inf，与第 3 步矛盾。故 A_+ 非有限生成，U(g) 非左 Noetherian。证毕（叙述级，非形式化）。
