## 命题

设 1 ≤ p < ∞，n ∈ R³ 为单位向量且 n 至少有一个坐标为 0。记 A_p(n) 为 B_p^3 = {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1} 与平面 n^⊥ 的交的二维 Lebesgue 面积，C_p := A_p(e_3)。则：(i) 若 i 是使 n_i = 0 的任一下标，则 A_p(n) = C_p·(Σ_{j≠i}|n_j|^p)^{-1/p}，右端不依赖 i 的选取，且 C_p = 4Γ(1+1/p)²/Γ(1+2/p)；(ii) 当 1 ≤ p < 2 时 A_p(n) ≤ C_p，等号成立当且仅当 n 是 ±坐标向量；(iii) 当 p > 2 时 A_p(n) ≥ C_p，等号成立当且仅当 n 是 ±坐标向量；(iv) p = 2 时对一切这样的 n 有 A_2(n) = π = C_2，且门槛 p = 2 是精确的：对每个 p ≠ 2，法向 n = (1,1,0)/√2 给出 A_p(n) ≠ C_p（p < 2 时严格小、p > 2 时严格大）。

## 证明

设 1 ≤ p < ∞，n 是 R³ 中的单位向量且至少有一个坐标为零。记 B_p^3 = {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}，A_p(n) 为 B_p^3 与平面 n^⊥ 的交在该平面上的二维 Lebesgue 面积，并记 C_p := A_p(e_3)。以下分四步：先把问题化到标准位置，再写出 A_p(n) 的闭式，然后比较它与 C_p 的大小，最后说明门槛 p = 2 是精确的。

第一步是把问题化到标准位置。由于 B_p^3 在带符号坐标置换下不变（这类变换只是把 |x_1|,|x_2|,|x_3| 重新排列），而二维 Lebesgue 面积在平面的等距变换下不变，我们可以假设那个为零的坐标就是第三个，即 n = (a,b,0)，其中 a²+b² = 1。由这一对称性，一般情形的结论随之成立，而且最终表达式对「哪一个下标取零」并不敏感，这正是 (i) 中「右端不依赖 i 的选取」的来源。

第二步取 n^⊥ 的一组单位正交基。令 u = (b,-a,0)、v = (0,0,1)。由 a²+b² = 1 直接验得 ‖u‖ = ‖v‖ = 1、u·v = 0、u·n = ab - ab = 0、v·n = 0，所以 {u,v} 确实是 n^⊥ 的单位正交基，映射 (s,z) ↦ s·u + z·v = (sb,-sa,z) 是 R² 到 n^⊥ 的等距同构，从而保持二维面积。

把这个参数化代入约束：点 (sb,-sa,z) 落在 B_p^3 内当且仅当 |sb|^p + |sa|^p + |z|^p ≤ 1，也就是 m|s|^p + |z|^p ≤ 1，其中 m := |a|^p + |b|^p。因为 a²+b² = 1，故 m > 0，这一步不会退化。记 E := {(s,z) : m|s|^p+|z|^p ≤ 1}；由上面那个等距同构，A_p(n) = area(E)。

第三步把 E 拉回标准区域 D_p := {(X,Y) : |X|^p+|Y|^p ≤ 1}。令 c := m^{1/p} > 0，考虑线性映射 T(s,z) := (cs,z)，其行列式为 det T = c。由 |cs|^p = m|s|^p 得：(s,z) ∈ E 当且仅当 T(s,z) ∈ D_p，即 T(E) = D_p；并且 T 是双射，逆映射为 (X,Y) ↦ (X/c,Y)。由面积在可逆线性映射下的变换律 area(T(E)) = |det T|·area(E)，得 c·area(E) = area(D_p)，于是 A_p(n) = area(E) = m^{-1/p}·area(D_p)。

第四步算 area(D_p)。由四个象限的对称性，area(D_p) = 4∫_0^1 (1-t^p)^{1/p} dt。令 u = t^p，则 t = u^{1/p}、dt = p^{-1}u^{1/p-1}du，故 ∫_0^1 (1-t^p)^{1/p} dt = p^{-1}∫_0^1 u^{1/p-1}(1-u)^{1/p} du = p^{-1}B(1/p,1+1/p)，这里用的是 Beta 函数的积分表示 ∫_0^1 u^{α-1}(1-u)^{β-1}du = B(α,β)，取 α = 1/p、β = 1+1/p。于是 area(D_p) = 4p^{-1}B(1/p,1+1/p) = 4Γ(1/p)Γ(1+1/p)/(pΓ(1+2/p))；再用 Γ(1/p) = pΓ(1+1/p)（即 Γ(x+1) = xΓ(x) 取 x = 1/p）约去 p，得 area(D_p) = 4Γ(1+1/p)²/Γ(1+2/p) =: C_p。这一步同时给出了 (i) 中 C_p 的闭式。

有了 A_p(n) = m^{-1/p}·C_p，余下的工作全部归结为比较 m 与 1。先看 1 ≤ p < 2 的情形：对 0 ≤ t ≤ 1 有 t^p ≥ t²，等号成立当且仅当 t ∈ {0,1}。事实上 t = 0 时两边都是 0；t > 0 时 t^p ≥ t² 等价于 t^{p-2} ≥ 1，也就是 t^{2-p} ≤ 1，而 2-p > 0 时该式在 (0,1] 上只在 t = 1 取等。再看 p > 2 的情形：同样的论证把 p-2 换成 2-p < 0，得到 t^p ≤ t²，等号同样只在 t ∈ {0,1}。

因为 |a|,|b| ≤ 1，把上一条用于 t = |a| 与 t = |b| 即得：当 1 ≤ p < 2 时 m = |a|^p+|b|^p ≥ |a|²+|b|² = 1，故 m^{-1/p} ≤ 1，等号成立当且仅当 |a|^p = |a|² 且 |b|^p = |b|²，也就是 a,b ∈ {0,±1}，配合 a²+b² = 1 即 n 为 ±坐标向量。同理，当 p > 2 时 m ≤ 1，故 m^{-1/p} ≥ 1，等号的刻画完全相同。代回 A_p(n) = m^{-1/p}·C_p 就得到 (ii) 与 (iii)。而当 p = 2 时 m = a²+b² = 1，故 A_2(n) = C_2；再由前面 area(D_p) 的闭式，C_2 = 4Γ(3/2)²/Γ(2) = 4·(π/4) = π，这给出 (iv) 的前半。

最后说明门槛 p = 2 是精确的，即 (iv) 的后半。取 n = (1,1,0)/√2，则 a = b = 1/√2、m = 2·(1/√2)^p = 2^{1-p/2}，故 m^{-1/p} = 2^{-(1-p/2)/p} = 2^{1/2-1/p}，于是 A_p(n) = C_p·2^{1/2-1/p}。当 1 ≤ p < 2 时指数 1/2-1/p < 0，故 2^{1/2-1/p} < 1，从而 A_p(n) < C_p；当 p > 2 时该指数为正，A_p(n) > C_p；而 p = 2 时指数为 0，A_p(n) = C_2 = π，与前面的结论一致。这既说明对每个 p ≠ 2 都有 A_p(n) ≠ C_p，也给出 (ii)/(iii) 中「严格」的显式见证。
