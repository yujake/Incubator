## 命题

设 1 ≤ p < ∞，B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}；对单位向量 n 记 A_p(n) 为 B_p^3 ∩ n^⊥ 在平面 n^⊥ 上的二维 Lebesgue 面积，并记 A_face(p) := A_p((1,1,0)/√2)、A_diag(p) := A_p((1,1,1)/√3)、Δ(p) := A_face(p) − A_diag(p)。则：(i) A_diag(p) = (√3/2)∫_0^{2π} (|cosθ|^p+|sinθ|^p+|cosθ+sinθ|^p)^{-2/p} dθ，且 A_diag(2) = π、A_diag(1) = 3√3/4、lim_{p→∞}A_diag(p) = 3√3；(ii) A_face(p) = 2^{1/2−1/p}·4Γ(1+1/p)²/Γ(1+2/p)，且 A_face(2) = π、A_face(1) = √2、lim_{p→∞}A_face(p) = 4√2；(iii) Δ 在 [1,∞) 上连续，Δ(2) = 0，Δ(1) = √2 − 3√3/4 > 0，lim_{p→∞}Δ(p) = 4√2 − 3√3 > 0，因而存在 P0 ∈ [1,∞) 使一切 p ≥ P0 满足 A_face(p) > A_diag(p)。

## 证明

设 p ∈ [1,∞) 固定。记 B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}；对单位向量 n，记 A_p(n) 为 B_p^3 ∩ n^⊥ 在平面 n^⊥ 上的二维 Lebesgue 面积；并记 A_face(p) := A_p((1,1,0)/√2)、A_diag(p) := A_p((1,1,1)/√3)、Δ(p) := A_face(p) − A_diag(p)。

一、先把 A_diag 写成平面 H := {x+y+z=0} 上的极坐标积分。取 u := (1,-1,0)/√2 与 v := (1,1,-2)/√6。直接验算得 ‖u‖ = ‖v‖ = 1、u·v = 0，又 u·(1,1,1) = 0、v·(1,1,1) = 0，故 {u,v} 是 H 的一组单位正交基，而 n := (1,1,1)/√3 是 H 的单位法向量、H = n^⊥。在 H 上以 (u,v) 为基取极坐标 x = r·e(θ)，其中 e(θ) := cosθ·u + sinθ·v、r ≥ 0、θ ∈ [0,2π)。由于 l_p 范数是正齐次的，‖x‖_p = r‖e(θ)‖_p，于是 x ∈ B_p^3 当且仅当 r ≤ ‖e(θ)‖_p^{-1}。平面极坐标的面积元带 Jacobi 因子 r，先对 r 积分得 ∫_0^{‖e(θ)‖_p^{-1}} r dr = (1/2)‖e(θ)‖_p^{-2}，再对 θ 积分便有 A_diag(p) = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ，这就是 (i) 的第一个等号。

二、把 ‖e(θ)‖_p 算出来。由 u、v 的分量得 e_1 = cosθ/√2 + sinθ/√6 = (√3cosθ+sinθ)/√6、e_2 = −cosθ/√2 + sinθ/√6 = −(√3cosθ−sinθ)/√6、e_3 = −2sinθ/√6。用余弦的差角公式 √3cosθ+sinθ = 2cos(θ−π/6) 与 √3cosθ−sinθ = 2cos(θ+π/6)，得 |e_1| = (2/√6)|cos(θ−π/6)|、|e_2| = (2/√6)|cos(θ+π/6)|、|e_3| = (2/√6)|sinθ|。记 S(θ) := |cos(θ−π/6)|^p+|cos(θ+π/6)|^p+|sinθ|^p，则 ‖e(θ)‖_p^p = (2/√6)^p·S(θ)；因为 (2/√6)² = 2/3，两边取 −2/p 次幂得 ‖e(θ)‖_p^{-2} = (3/2)·S(θ)^{-2/p}。代回上一段，便得 (i) 的第二个等号 A_diag(p) = (3/4)∫_0^{2π} S(θ)^{-2/p} dθ。

三、另一条路把同一个面积写进 (x,y) 平面，这给出 (ii)。H 上的点可唯一写成 (x,y,−x−y)，即 Φ(x,y) := (x,y,−x−y) 是 R² 到 H 的双射；它的偏导向量 ∂_xΦ = (1,0,−1) 与 ∂_yΦ = (0,1,−1) 的叉积为 (1,1,1)、模为 √3，故曲面面积公式给出 A_diag(p) = √3∫∫_D dx dy，其中 D := {(x,y) : |x|^p+|y|^p+|x+y|^p ≤ 1}。再对 D 用平面极坐标 (x,y) = r(cosθ, sinθ)：记 g(θ) := |cosθ|^p+|sinθ|^p+|cosθ+sinθ|^p，由 |r cosθ|^p+|r sinθ|^p+|r(cosθ+sinθ)|^p = r^p g(θ) 得 (x,y) ∈ D 当且仅当 r ≤ g(θ)^{-1/p}；用面积元 r dr dθ 先对 r 积分得 ∫_0^{g(θ)^{-1/p}} r dr = (1/2)g(θ)^{-2/p}，于是 A_diag(p) = (√3/2)∫_0^{2π} g(θ)^{-2/p} dθ。两条路算的是同一个 A_diag，故上面三个积分表示彼此相等；下文算特例值时用 g(θ) 这一式。

四、A_face 的闭式。取 n_face := (1,1,0)/√2，则 n_face^⊥ 是平面 x+y=0。用 (x,z) ↦ (x,−x,z) 参数化这个平面：两个偏导 (1,−1,0) 与 (0,0,1) 的叉积为 (−1,−1,0)、模为 √2，而该点的 l_p 范数的 p 次幂是 2|x|^p+|z|^p，故 A_face(p) = √2·area{(x,z) : 2|x|^p+|z|^p ≤ 1}。作代换 u := 2^{1/p}x，即 x = 2^{-1/p}u、dx = 2^{-1/p}du，则 2|x|^p = |u|^p，于是 A_face(p) = √2·2^{-1/p}·S_p，其中 S_p := area{(u,z) : |u|^p+|z|^p ≤ 1}。算 S_p：由对称性与竖向切片（固定 u 时 |z| ≤ (1−|u|^p)^{1/p}）得 S_p = 4∫_0^1 (1−u^p)^{1/p} du。作代换 t = u^p（u = t^{1/p}、du = (1/p)t^{1/p−1}dt）把积分化为 Beta 积分：4∫_0^1 (1−u^p)^{1/p} du = (4/p)∫_0^1 t^{1/p−1}(1−t)^{1/p} dt = (4/p)B(1/p, 1+1/p) = (4/p)·Γ(1/p)Γ(1+1/p)/Γ(1+2/p) = 4Γ(1+1/p)²/Γ(1+2/p)，最后一步用了 Γ(1+1/p) = Γ(1/p)/p。代回上式即得 (ii) 的闭式 A_face(p) = 2^{1/2−1/p}·4Γ(1+1/p)²/Γ(1+2/p)。

五、特例值。p = 2 时 g(θ) = cos²θ+sin²θ+(cosθ+sinθ)² = 2+sin2θ，而 g^{-2/p} 在 p = 2 处就是 g^{-1}，故 A_diag(2) = (√3/2)∫_0^{2π} dθ/(2+sin2θ)。作代换 u = 2θ：θ 走一整圈对应 u 走两圈、且 sin 以 2π 为周期，故 ∫_0^{2π} dθ/(2+sin2θ) = (1/2)∫_0^{4π} du/(2+sin u) = ∫_0^{2π} du/(2+sin u)；再用 ∫_0^{2π} du/(a+b sin u) = 2π/√(a²−b²)（取 a = 2、b = 1）得它为 2π/√3，于是 A_diag(2) = (√3/2)·(2π/√3) = π。同一 p = 2 下 S_2 = 4∫_0^1 √(1−u²) du = 4·(π/4) = π，而 2^{1/2−1/2} = 1，故 A_face(2) = π。两者相等，于是 Δ(2) = 0。

p = 1 时 g(θ) = |cosθ|+|sinθ|+|cosθ+sinθ|，满足 g(θ+π) = g(θ)，故只需算 [0,π] 上的积分再乘 2。在 [0,π/2] 上三项都非负，g = 2(cosθ+sinθ)，从而 g^{-2} = (1/4)(cosθ+sinθ)^{-2}；把 cosθ+sinθ 写成 √2sin(θ+π/4)，代换 φ = θ+π/4 得 ∫_0^{π/2} dθ/(cosθ+sinθ)² = (1/2)∫_{π/4}^{3π/4} dφ/sin²φ = (1/2)[−cotφ] 在两端取值之差 = 1，故这一段贡献 1/4。在 [π/2,3π/4] 上 cosθ ≤ 0 而 cosθ+sinθ ≥ 0，故 g = 2sinθ、g^{-2} = (1/4)sin^{-2}θ，而 ∫_{π/2}^{3π/4} dθ/sin²θ = [−cotθ] 在两端取值之差为 1，这一段也贡献 1/4。在 [3π/4,π] 上 cosθ+sinθ ≤ 0，故 g = −2cosθ、g^{-2} = (1/4)cos^{-2}θ，而 ∫_{3π/4}^{π} dθ/cos²θ = [tanθ] 在两端取值之差为 1，这一段同样贡献 1/4。三段相加得 ∫_0^{2π} g^{-2} dθ = 2·(3/4) = 3/2，于是 A_diag(1) = (√3/2)·(3/2) = 3√3/4。另一边 S_1 = 4∫_0^1 (1−u) du = 2，而 2^{-1/1} = 1/2，故 A_face(1) = √2·(1/2)·2 = √2。于是 Δ(1) = √2 − 3√3/4，它是正的，因为 4√2 > 3√3 等价于平方后的 32 > 27。

六、p → ∞ 的极限。记 m(θ) := max(|cosθ|,|sinθ|,|cosθ+sinθ|)。因为 g(θ) 是三项之和，每一项都不超过 m(θ)^p 而其中至少有一项恰等于 m(θ)^p，故 m(θ)^p ≤ g(θ) ≤ 3m(θ)^p；两边取 −2/p 次幂并令 p → ∞（此时 3^{-2/p} → 1），得对每个 θ 都有 g(θ)^{-2/p} → m(θ)^{-2}。至于控制：由 g ≥ m^p 得 g^{-2/p} ≤ m^{-2}，而 m(θ) ≥ max(|cosθ|,|sinθ|) ≥ 1/√2，故 m(θ)^{-2} ≤ 2，于是对一切 p ≥ 1 与一切 θ 都有与 p 无关的界 g(θ)^{-2/p} ≤ 2。有界收敛定理给出 A_diag(p) → (√3/2)∫_0^{2π} m(θ)^{-2} dθ。剩下的积分按符号分段算出：在 [0,π/2] 上 m = cosθ+sinθ、在 [π/2,3π/4] 上 m = sinθ、在 [3π/4,π] 上 m = −cosθ，且 m(θ+π) = m(θ)；三段各自的积分与上一步 p = 1 时算过的三段相同、各为 1，故 ∫_0^{2π} m^{-2} dθ = 2·3 = 6，于是 lim_{p→∞} A_diag(p) = (√3/2)·6 = 3√3。另一边，S_p 关于 p 单调不减：若 |u|^p+|z|^p ≤ 1 而 p' > p，则必有 |u| ≤ 1 与 |z| ≤ 1，从而 |u|^{p'}+|z|^{p'} ≤ |u|^p+|z|^p ≤ 1。再看这族集合的并 E := ∪_{p≥1} {(u,z) : |u|^p+|z|^p ≤ 1}：一方面，|u|^p+|z|^p ≤ 1 迫使 |u| ≤ 1 与 |z| ≤ 1，故 E 落在闭正方形 [−1,1]² 之内；另一方面，任给 (u,z) ∈ (−1,1)² 有 max(|u|,|z|) < 1，于是 max(|u|,|z|)^p → 0，充分大的 p 便使 |u|^p+|z|^p ≤ 1，故整个开正方形 (−1,1)² 都含在 E 里。合起来，E 与 (−1,1)² 只差 [−1,1]² 的边界那一段零测集；(−1,1)² 是边长 2 的开正方形（四个象限各占其四分之一），面积为 4，于是 E 的面积也是 4。由单调收敛定理得 S_p ↑ 4，于是 lim_{p→∞} A_face(p) = √2·1·4 = 4√2。与上一条合并得 lim_{p→∞} Δ(p) = 4√2 − 3√3，它同样是正的（仍由 32 > 27）。

七、连续性。先看 A_face：S_p = 4∫_0^1 (1−u^p)^{1/p} du 的被积函数关于 (p,u) ∈ [1,∞)×[0,1] 连续（u = 1 处它恒取值 0），且被常数 1 控制，故由有界收敛定理 p ↦ S_p 在 [1,∞) 上连续；又 p ↦ 2^{-1/p} 连续，于是 A_face 在 [1,∞) 上连续。再看 A_diag：由上面那条与 p 无关的控制 g(θ)^{-2/p} ≤ 2 以及 g 关于 (p,θ) 的联合连续性，对任意收敛序列 p_k → p 都有 g^{-2/p_k} → g^{-2/p} 逐点成立且被常数 2 控制，故有界收敛定理给出 p ↦ ∫_0^{2π} g(θ)^{-2/p} dθ 连续；A_diag 就是它乘常数 √3/2，故 A_diag 也连续。两者相减，Δ 在 [1,∞) 上连续。

八、收尾。记 L := 4√2 − 3√3 > 0，取 ε := L/2 > 0。由 Δ 的连续性与 lim_{p→∞} Δ(p) = L，存在 P0 ∈ [1,∞) 使一切 p ≥ P0 满足 |Δ(p) − L| < ε，从而 Δ(p) > L/2 > 0，即 A_face(p) > A_diag(p) 对一切 p ≥ P0 成立。至此 (i)(ii)(iii) 全部成立。
