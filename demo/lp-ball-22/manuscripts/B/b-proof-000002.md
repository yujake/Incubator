## 命题

设 1 ≤ p < ∞，B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}，H := {(x,y,z) : x+y+z = 0}，A_diag(p) 为 H∩B_p^3 在平面 H 上（取 R^3 诱导的内积与二维 Lebesgue 面积）的面积。取 H 的单位正交基 u = (1,-1,0)/√2、v = (1,1,-2)/√6，并对 θ∈[0,2π) 记 e(θ) := cosθ·u + sinθ·v。则：(i) A_diag(p) = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ = (3/4)∫_0^{2π} (|cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p)^{-2/p} dθ；(ii) A_diag(p) = √3·area{(x,y)∈R^2 : |x|^p+|y|^p+|x+y|^p ≤ 1} = (√3/2)∫_0^{2π} (|cosθ|^p+|sinθ|^p+|cosθ+sinθ|^p)^{-2/p} dθ；(iii) A_diag(1) = 3√3/4，A_diag(2) = π，lim_{p→∞} A_diag(p) = 3√3；(iv) p ↦ A_diag(p) 在 [1,∞) 上连续。

## 证明

设 p∈[1,∞) 固定。记 B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}，H := {(x,y,z) : x+y+z = 0}，而 A_diag(p) 是 H∩B_p^3 在平面 H 上的二维 Lebesgue 面积。取 u := (1,-1,0)/√2 与 v := (1,1,-2)/√6。直接验算内积可得 ‖u‖² = (1+1+0)/2 = 1、‖v‖² = (1+1+4)/6 = 1、u·v = (-1+1+0)/√12 = 0，又 u·(1,1,1) = 0、v·(1,1,1) = 0，故 {u,v} 是 H 的一组单位正交基，映射 (s,t) ↦ s·u + t·v 是 R² 到 H 的等距同构。记 n := (1,1,1)/√3，它是 H 的单位法向量，于是 H = n^⊥。

先把 A_diag(p) 写成平面上的积分。由在册命题 stmt:000034 的 (i)，对任意单位法向与 n^⊥ 的任意一组单位正交基都有 A_p(n) = (1/2)∫_0^{2π}‖cosθ·u + sinθ·v‖_p^{-2} dθ，且该值不随基的选取而变。为不使这一步只靠外部引用，这里把它的来源重述一遍：记 e(θ) := cosθ·u + sinθ·v，在 H 上以 (u,v) 为基取极坐标 x = r·e(θ)（r ≥ 0）；由 l_p 范数的正齐次性得 ‖x‖_p = r‖e(θ)‖_p，于是 x ∈ B_p^3 当且仅当 r ≤ ‖e(θ)‖_p^{-1}。平面极坐标的面积元带 Jacobi 因子 r，故先对 r 积分得 ∫_0^{‖e(θ)‖_p^{-1}} r dr = (1/2)‖e(θ)‖_p^{-2}，再对 θ 积分便得 A_diag(p) = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ。这就是 (i) 的第一个等号。

接着把 e(θ) 的三个坐标算出来。由 u、v 的分量，e_1 = cosθ/√2 + sinθ/√6 = (√3cosθ + sinθ)/√6，e_2 = -cosθ/√2 + sinθ/√6 = -(√3cosθ - sinθ)/√6，e_3 = -2sinθ/√6。用余弦的差角公式，即 √3cosθ + sinθ = 2cos(θ-π/6) 与 √3cosθ - sinθ = 2cos(θ+π/6)，得 |e_1| = (2/√6)|cos(θ-π/6)|、|e_2| = (2/√6)|cos(θ+π/6)|、|e_3| = (2/√6)|sinθ|。

记 S(θ) := |cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p。把上一段的三个绝对值代入并提公因子 (2/√6)^p，得 ‖e(θ)‖_p^p = (2/√6)^p·S(θ)。因为 (2/√6)² = 4/6 = 2/3，两边取 -2/p 次幂（p ≥ 1 时这是单调的正幂运算）便得 ‖e(θ)‖_p^{-2} = ((2/√6)^p S(θ))^{-2/p} = (2/3)^{-1}·S(θ)^{-2/p} = (3/2)·S(θ)^{-2/p}。

把这一段代回上上一段，A_diag(p) = (1/2)·(3/2)∫_0^{2π} S(θ)^{-2/p} dθ = (3/4)∫_0^{2π} (|cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p)^{-2/p} dθ，这就是 (i) 的第二个等号。

现在换到 (x,y) 坐标来算 (ii) 的第一个等号。H 上的点可唯一地写成 (x,y,-x-y)，即 Φ(x,y) := (x,y,-x-y) 是 R² 到 H 的双射；它的两个偏导向量 ∂_xΦ = (1,0,-1) 与 ∂_yΦ = (0,1,-1) 的叉积为 (1,1,1)、模为 √3，所以曲面面积公式给出：像的面积等于原像面积乘以 √3。又 Φ(x,y) ∈ B_p^3 当且仅当 |x|^p + |y|^p + |x+y|^p ≤ 1，故 A_diag(p) = √3∫∫_D dxdy，其中 D := {(x,y) : |x|^p + |y|^p + |x+y|^p ≤ 1}。

(ii) 的第二个等号再对 D 用平面极坐标。记 g(θ) := |cosθ|^p + |sinθ|^p + |cosθ+sinθ|^p，把 (x,y) = r(cosθ, sinθ) 代入得 |r cosθ|^p + |r sinθ|^p + |r(cosθ+sinθ)|^p = r^p·g(θ)，于是 (x,y) ∈ D 当且仅当 r ≤ g(θ)^{-1/p}。由面积元 r dr dθ，∫∫_D = ∫_0^{2π}∫_0^{g(θ)^{-1/p}} r dr dθ = (1/2)∫_0^{2π} g(θ)^{-2/p} dθ；这里内层积分已经产出 1/2 这个因子，外层只积一次，不再另加因子。与上一段合并即得 (ii)。

关于 (iii)，先算 p = 2 与 p = 1 两个特例。p = 2 时 g(θ) = cos²θ + sin²θ + (cosθ+sinθ)² = 2 + sin2θ，而 g^{-2/p} 在 p = 2 处就是 g^{-1}，故 A_diag(2) = (√3/2)∫_0^{2π} dθ/(2+sin2θ)。作代换 u = 2θ：由于 sin 以 2π 为周期，θ 走一整圈对应 u 走两圈，故 ∫_0^{2π} dθ/(2+sin2θ) = (1/2)∫_0^{4π} du/(2+sin u) = ∫_0^{2π} du/(2+sin u)。再用 ∫_0^{2π} du/(a+b sin u) = 2π/√(a²-b²)（取 a = 2、b = 1）得该积分为 2π/√3，于是 A_diag(2) = (√3/2)·(2π/√3) = π。

p = 1 时 g(θ) = |cosθ| + |sinθ| + |cosθ+sinθ|。注意 g(θ+π) = g(θ)，故只需算出 [0,π] 上的积分再乘 2。在 [0,π] 上按 cosθ+sinθ 的符号分成三段。第一段 [0,π/2]：这里 cosθ 与 sinθ 都非负，g = 2(cosθ+sinθ)，故 g^{-2} = (1/4)(cosθ+sinθ)^{-2}，而 ∫_0^{π/2} dθ/(cosθ+sinθ)² = 1（把 cosθ+sinθ 写成 √2cos(θ-π/4)，代换 φ = θ-π/4 后用 tan 的原函数即得），故这一段贡献 1/4。第二段 [π/2,3π/4]：这里 cosθ ≤ 0 而 sum 非负，g = 2sinθ，故 g^{-2} = (1/4)sin^{-2}θ，而 ∫_{π/2}^{3π/4} dθ/sin²θ = [-cotθ] 在两端取值之差为 1，故这一段也贡献 1/4。第三段 [3π/4,π]：这里 cosθ+sinθ ≤ 0，g = -2cosθ，故 g^{-2} = (1/4)cos^{-2}θ，而 ∫_{3π/4}^{π} dθ/cos²θ = [tanθ] 在两端取值之差为 1，故这一段同样贡献 1/4。三段相加得 ∫_0^{π} g^{-2}dθ = 3/4，于是 ∫_0^{2π} g^{-2}dθ = 2·(3/4) = 3/2，从而 A_diag(1) = (√3/2)·(3/2) = 3√3/4。

最后处理 p → ∞ 与 (iv) 的连续性。记 m(θ) := max(|cosθ|, |sinθ|, |cosθ+sinθ|)。因为 g(θ) 是三项之和，每一项都不超过 m(θ)^p 而其中至少一项恰等于 m(θ)^p，所以 m(θ)^p ≤ g(θ) ≤ 3m(θ)^p；两边取 -2/p 次幂并令 p → ∞，3^{-2/p} → 1，故对每个 θ 都有 g(θ)^{-2/p} → m(θ)^{-2}。控制方面，由 g ≥ m^p 得 g^{-2/p} ≤ m^{-2}；又 m(θ) ≥ max(|cosθ|,|sinθ|) ≥ 1/√2（两个数的最大者不小于它们平方平均的平方根），故 m(θ)^{-2} ≤ 2，于是对一切 p ≥ 1 与一切 θ 都有与 p 无关的界 g(θ)^{-2/p} ≤ 2。有界收敛定理于是给出 A_diag(p) → (√3/2)∫_0^{2π} m(θ)^{-2}dθ。剩下的积分按同样的分段算出：在 [0,π/2] 上 m = cosθ+sinθ，在 [π/2,3π/4] 上 m = sinθ，在 [3π/4,π] 上 m = -cosθ，且 m(θ+π) = m(θ)；三段各自的积分与 p = 1 那一步算过的三段相同、各为 1，故 ∫_0^{2π} m^{-2}dθ = 2·(1+1+1) = 6，极限为 (√3/2)·6 = 3√3。至于 (iv)：g 关于 (p,θ) 联合连续，而对任意收敛序列 p_k → p 都有上面那一个与 k 无关的控制 g^{-2/p_k} ≤ 2，故有界收敛定理可用来取极限，得 p ↦ ∫_0^{2π} g(θ)^{-2/p}dθ 在 [1,∞) 上连续；A_diag 就是它乘常数 √3/2，故 p ↦ A_diag(p) 在 [1,∞) 上连续。

以上四段合起来即 (i)–(iv) 全部成立。
