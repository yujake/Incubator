## 命题

设 1 ≤ p < ∞，n ∈ R³ 为单位向量且 n 至少有一个坐标为 0。记 A_p(n) 为 B_p^3 = {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1} 与平面 n^⊥ 的交的二维 Lebesgue 面积，C_p := A_p(e_3)。则：(i) 若 i 是使 n_i = 0 的任一下标，则 A_p(n) = C_p·(Σ_{j≠i}|n_j|^p)^{-1/p}，右端不依赖 i 的选取，且 C_p = 4Γ(1+1/p)²/Γ(1+2/p)；(ii) 当 1 ≤ p < 2 时 A_p(n) ≤ C_p，等号成立当且仅当 n 是 ±坐标向量；(iii) 当 p > 2 时 A_p(n) ≥ C_p，等号成立当且仅当 n 是 ±坐标向量；(iv) p = 2 时对一切这样的 n 有 A_2(n) = π = C_2，且门槛 p = 2 是精确的：对每个 p ≠ 2，法向 n = (1,1,0)/√2 给出 A_p(n) ≠ C_p（p < 2 时严格小、p > 2 时严格大）。

## 证明

1. 前提：p ∈ [1,∞)；n 为单位向量且存在下标 i 使 n_i = 0；B_p^3 在带符号坐标置换下不变、二维 Lebesgue 面积在平面的正交变换下不变，故不妨设 i = 3、n = (a,b,0) 且 a²+b² = 1。（前提）
2. 前提：取 u = (b,-a,0)、v = (0,0,1)。由 a²+b² = 1 直接验得 ‖u‖ = ‖v‖ = 1、u·v = 0、u·n = ab-ab = 0、v·n = 0，故 {u,v} 是 n^⊥ 的单位正交基，映射 (s,z) ↦ s·u + z·v = (sb,-sa,z) 是 R² → n^⊥ 的等距同构。（前提）
3. 前提：把该参数化代入约束得 x ∈ B_p^3 ⟺ |sb|^p + |-sa|^p + |z|^p ≤ 1 ⟺ m|s|^p + |z|^p ≤ 1，其中 m := |a|^p+|b|^p ∈ (0,∞)（a²+b² = 1 保证 m > 0）；记 E := {(s,z) : m|s|^p+|z|^p ≤ 1}，由等距同构得 A_p(n) = area(E)。（前提）
4. 前提：取 c := m^{1/p} > 0 与线性映射 T(s,z) := (cs,z)（det T = c）。由 |cs|^p = m|s|^p 得 (s,z) ∈ E ⟺ T(s,z) ∈ D_p := {(X,Y) : |X|^p+|Y|^p ≤ 1}，即 T(E) = D_p；且 T 是双射（逆为 (X,Y) ↦ (X/c,Y)）。（前提）
5. 前提：由面积在可逆线性映射下的变换律 area(T(E)) = |det T|·area(E) 与 T(E) = D_p 得 c·area(E) = area(D_p)，即 area(E) = c^{-1}·area(D_p) = m^{-1/p}·area(D_p)。（前提）
6. 前提：算 area(D_p)。由四象限对称 area(D_p) = 4∫_0^1 (1-t^p)^{1/p} dt。令 u = t^p，则 t = u^{1/p}、dt = p^{-1}u^{1/p-1}du，故 ∫_0^1 (1-t^p)^{1/p}dt = p^{-1}∫_0^1 (1-u)^{1/p}u^{1/p-1}du = p^{-1}B(1/p, 1+1/p)（用 ∫_0^1 u^{a-1}(1-u)^{b-1}du = B(a,b)，取 a = 1/p、b = 1+1/p）。于是 area(D_p) = 4p^{-1}B(1/p,1+1/p) = 4Γ(1/p)Γ(1+1/p)/(pΓ(1+2/p))；再由 Γ(1/p) = pΓ(1+1/p)（Γ(x+1) = xΓ(x) 取 x = 1/p）约去 p 得 area(D_p) = 4Γ(1+1/p)²/Γ(1+2/p) =: C_p。（前提）
7. 前提：当 1 ≤ p < 2 时，对 0 ≤ t ≤ 1 有 t^p ≥ t²，等号成立当且仅当 t ∈ {0,1}（t = 0 时两边为 0；t > 0 时 t^p ≥ t² ⟺ t^{p-2} ≥ 1 ⟺ t^{2-p} ≤ 1，而 2-p > 0 时该式在 (0,1] 上仅在 t = 1 取等）。（前提）
8. 前提：当 p > 2 时，对 0 ≤ t ≤ 1 有 t^p ≤ t²，等号成立当且仅当 t ∈ {0,1}（同上，把 p-2 换成 2-p < 0）。（前提）
9. 前提：由第 7、8 步并用 |a|,|b| ≤ 1：1 ≤ p < 2 时 m = |a|^p+|b|^p ≥ |a|²+|b|² = 1，故 m^{-1/p} ≤ 1，等号 ⟺ |a|^p = |a|² 且 |b|^p = |b|² ⟺ a,b ∈ {0,±1}（配合 a²+b² = 1 即 n 为 ±坐标向量）；p > 2 时同理 m ≤ 1，故 m^{-1/p} ≥ 1，等号刻画相同。代入第 5 步得 (ii) 与 (iii)。p = 2 时 m = a²+b² = 1，故 A_2(n) = C_2，且由第 6 步的闭式 C_2 = 4Γ(3/2)²/Γ(2) = 4·(π/4) = π，即 (iv) 的前半。（前提）
10. 前提：门槛精确性。取 n = (1,1,0)/√2，则 a = b = 1/√2、m = 2·(1/√2)^p = 2^{1-p/2}，故 m^{-1/p} = 2^{-(1-p/2)/p} = 2^{-1/p+1/2} = 2^{1/2-1/p}，于是 A_p(n) = C_p·2^{1/2-1/p}。当 1 ≤ p < 2 时 1/2-1/p < 0，故 2^{1/2-1/p} < 1，A_p(n) < C_p；当 p > 2 时 1/2-1/p > 0，故 A_p(n) > C_p；而 p = 2 时指数为 0、A_2(n) = C_2 = π（与第 9 步一致）。这给出门槛 p = 2 的精确性，也给出 (ii)/(iii) 中「严格」的显式见证。（前提）
