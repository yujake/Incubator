## 命题

设 1 ≤ p < ∞，B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}，H := {(x,y,z) : x+y+z = 0}，A_diag(p) 为 H∩B_p^3 在平面 H 上（取 R^3 诱导的内积与二维 Lebesgue 面积）的面积。取 H 的单位正交基 u = (1,-1,0)/√2、v = (1,1,-2)/√6，并对 θ∈[0,2π) 记 e(θ) := cosθ·u + sinθ·v。则：(i) A_diag(p) = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ = (3/4)∫_0^{2π} (|cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p)^{-2/p} dθ；(ii) A_diag(p) = √3·area{(x,y)∈R^2 : |x|^p+|y|^p+|x+y|^p ≤ 1} = (√3/2)∫_0^{2π} (|cosθ|^p+|sinθ|^p+|cosθ+sinθ|^p)^{-2/p} dθ；(iii) A_diag(1) = 3√3/4，A_diag(2) = π，lim_{p→∞} A_diag(p) = 3√3；(iv) p ↦ A_diag(p) 在 [1,∞) 上连续。

## 证明

1. 【前提】固定 p∈[1,∞)；B_p^3 := {(x,y,z) : |x|^p+|y|^p+|z|^p ≤ 1}；H := {(x,y,z) : x+y+z = 0}；A_diag(p) := H∩B_p^3 在平面 H 上的二维 Lebesgue 面积。（前提）（前提）
2. 【前提】u := (1,-1,0)/√2、v := (1,1,-2)/√6。直接验算：‖u‖^2 = (1+1+0)/2 = 1，‖v‖^2 = (1+1+4)/6 = 1，u·v = (-1+1+0)/√12 = 0，u·(1,1,1) = (1-1+0)/√2 = 0，v·(1,1,1) = (1+1-2)/√6 = 0；故 {u,v} 是 H 的单位正交基，(s,t) ↦ s·u + t·v 是 R^2 → H 的等距同构。（前提）（前提）
3. 【推导】n := (1,1,1)/√3 是 H 的单位法向量，H = n^⊥。由 stmt:000034 的 (i)（该条在册、kind=theorem、status=active、五元位现算 pre_theorem；其陈述为：对任意单位法向与 n^⊥ 的任意单位正交基 {u,v}，A_p(n) = (1/2)∫_0^{2π}‖cosθ·u + sinθ·v‖_p^{-2} dθ，且该值不随基的选取而变）直接得到 A_diag(p) = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ；为免这一步只靠外部引用，同段内再给一遍该式的来源：在 n^⊥ 上取极坐标 x = r(cosθ·u + sinθ·v)（Jacobi 因子 r），由 l_p 范数的正齐次性 x ∈ B_p^3 ⟺ r ≤ ‖e(θ)‖_p^{-1}，内层积分 ∫_0^{‖e(θ)‖_p^{-1}} r dr = (1/2)‖e(θ)‖_p^{-2}，故面积 = (1/2)∫_0^{2π}‖e(θ)‖_p^{-2} dθ，与所引的 (i) 逐字一致。这给出 (i) 的第一个等号。（依据：stmt:000034）（依据：stmt:000034）
4. 【推导】把第 2 步的 u、v 分量代入 e(θ) = cosθ·u + sinθ·v 得 e_1 = cosθ/√2 + sinθ/√6 = (√3cosθ + sinθ)/√6，e_2 = -cosθ/√2 + sinθ/√6 = -(√3cosθ - sinθ)/√6，e_3 = -2sinθ/√6；对前两个分子用余弦差角公式（在 θ∓π/6 处展开 2cos 即得）√3cosθ + sinθ = 2cos(θ-π/6)、√3cosθ - sinθ = 2cos(θ+π/6)，于是 |e_1| = (2/√6)|cos(θ-π/6)|、|e_2| = (2/√6)|cos(θ+π/6)|、|e_3| = (2/√6)|sinθ|。（依据：stmt:000034）（依据：stmt:000034）
5. 【推导】记 S(θ) := |cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p。由第 4 步与 l_p 范数的正齐次性得 ‖e(θ)‖_p^p = Σ_i |e_i|^p = (2/√6)^p·S(θ)；又 (2/√6)^2 = 4/6 = 2/3，故 ‖e(θ)‖_p^{-2} = ((2/√6)^p S(θ))^{-2/p} = (2/3)^{-1}·S(θ)^{-2/p} = (3/2)·S(θ)^{-2/p}。（依据：stmt:000034）（依据：stmt:000034）
6. 【推导】把第 5 步代回第 3 步：A_diag(p) = (1/2)·(3/2)∫_0^{2π} S(θ)^{-2/p} dθ = (3/4)∫_0^{2π} (|cos(θ-π/6)|^p + |cos(θ+π/6)|^p + |sinθ|^p)^{-2/p} dθ，即 (i) 的第二个等号。（依据：stmt:000034）（依据：stmt:000034）
7. 【推导】(ii) 的第一个等号：H 上的点唯一写成 (x,y,-x-y)，映射 Φ(x,y) := (x,y,-x-y) 是 R^2 → H 的双射；其偏导向量 ∂_xΦ = (1,0,-1)、∂_yΦ = (0,1,-1) 的叉积为 (1,1,1)、模为 √3，故曲面面积公式给出 A_diag(p) = √3∫∫_D dx dy，其中 D := {(x,y) : |x|^p+|y|^p+|x+y|^p ≤ 1}（因为 Φ(x,y) ∈ B_p^3 ⟺ |x|^p+|y|^p+|x+y|^p ≤ 1）。（依据：stmt:000034）（依据：stmt:000034）
8. 【推导】(ii) 的第二个等号：记 g(θ) := |cosθ|^p + |sinθ|^p + |cosθ+sinθ|^p。对 D 用平面极坐标 (x,y) = r(cosθ, sinθ)（r ≥ 0，θ∈[0,2π)），由 |r cosθ|^p + |r sinθ|^p + |r(cosθ+sinθ)|^p = r^p g(θ) 得 (x,y)∈D ⟺ r ≤ g(θ)^{-1/p}；由面积元 r dr dθ 得 ∫∫_D = ∫_0^{2π}∫_0^{g(θ)^{-1/p}} r dr dθ = (1/2)∫_0^{2π} g(θ)^{-2/p} dθ（内层 ∫_0^{R} r dr = R^2/2 已含 1/2，外层不再另加因子），与第 7 步合并即得 (ii)。（依据：stmt:000034）（依据：stmt:000034）
9. 【推导】(iii) 的 p=2 与 p=1：(a) p=2 时 g(θ) = cos^2θ + sin^2θ + (cosθ+sinθ)^2 = 2 + sin2θ；由第 8 步的 g^{-2/p} 在 p=2 处化为 g^{-1}，得 A_diag(2) = (√3/2)∫_0^{2π} g(θ)^{-1} dθ = (√3/2)∫_0^{2π} dθ/(2+sin2θ)；代换 u = 2θ 得 ∫_0^{2π} dθ/(2+sin2θ) = (1/2)∫_0^{4π} du/(2+sin u) = ∫_0^{2π} du/(2+sin u) = 2π/√(2^2-1^2) = 2π/√3（用 ∫_0^{2π} du/(a+b sin u) = 2π/√(a^2-b^2)，取 a=2、b=1），故 A_diag(2) = (√3/2)·(2π/√3) = π。(b) p=1 时 g(θ) = |cosθ| + |sinθ| + |cosθ+sinθ|，注意 g(θ+π) = g(θ)，且按符号分段：在 [0,π/2] 上 g = 2(cosθ+sinθ)，故 g^{-2} = (1/4)(cosθ+sinθ)^{-2}；在 [π/2,3π/4] 上 g = 2sinθ，故 g^{-2} = (1/4)sin^{-2}θ；在 [3π/4,π] 上 g = -2cosθ，故 g^{-2} = (1/4)cos^{-2}θ。于是 ∫_0^{π/2} g^{-2}dθ = (1/4)∫_0^{π/2} dθ/(cosθ+sinθ)^2 = (1/4)·1 = 1/4（后者代 u=θ+π/4 用 csc^2 的原函数 -cot 得 ∫_0^{π/2} dθ/(cosθ+sinθ)^2 = 1），∫_{π/2}^{3π/4} g^{-2}dθ = (1/4)∫_{π/2}^{3π/4} dθ/sin^2θ = (1/4)[-cotθ] 取值为 (1/4)(1) = 1/4，∫_{3π/4}^{π} g^{-2}dθ = (1/4)∫_{3π/4}^{π} dθ/cos^2θ = (1/4)[tanθ] 取值为 (1/4)(1) = 1/4；故 ∫_0^{2π} g^{-2}dθ = 2∫_0^{π} g^{-2}dθ = 2(1/4+1/4+1/4) = 3/2，从而 A_diag(1) = (√3/2)·(3/2) = 3√3/4。（依据：stmt:000034）（依据：stmt:000034）
10. 【推导】(iii) 的 p→∞ 与 (iv)：记 m(θ) := max(|cosθ|, |sinθ|, |cosθ+sinθ|)，则 m(θ)^p ≤ g(θ) ≤ 3m(θ)^p，故对每个 θ 有 g(θ)^{-2/p} → m(θ)^{-2}；并且对一切 p ≥ 1 有与 p 无关的控制 g(θ)^{-2/p} ≤ m(θ)^{-2}（由 g ≥ m^p 两边取 -2/p 次幂即得），而 m(θ) ≥ max(|cosθ|,|sinθ|) ≥ 1/√2，故 m(θ)^{-2} ≤ 2；由控制收敛定理 A_diag(p) → (√3/2)∫_0^{2π} m(θ)^{-2} dθ。按符号分段：在 [0,π/2] 上 m = cosθ+sinθ，在 [π/2,3π/4] 上 m = sinθ，在 [3π/4,π] 上 m = -cosθ，且 m(θ+π) = m(θ)，于是 ∫_0^{2π} m^{-2} dθ = 2[1 + 1 + 1] = 6，极限为 (√3/2)·6 = 3√3。同一与 p 无关的控制 g(θ)^{-2/p} ≤ m(θ)^{-2} ≤ 2 与 g 关于 (p,θ) 的联合连续性还给出 p ↦ A_diag(p) 在 [1,∞) 上的连续性（对任意收敛序列用控制收敛），即 (iv)。（依据：stmt:000034）（依据：stmt:000034）
