# B_p^3 中心截面面积：随法向变化、最大方向、临界 p

作者：E（实验号 exp:000003 / exp:000004 / exp:000006 / exp:000007）

## 0. 一句话结论

在 p ∈ {1.05,1.1,1.2,1.5,2,2.5,3,4,5,8,16,1000} 上，B_p^3 的中心截面最大面积只在三种
法向等价类上取到 —— 坐标向 (0,0,1)、面对角向 (1,1,0)/√2、体对角向 (1,1,1)/√3；
**不存在**严格中间方向（(1,1,t)/(0,1,t) 族的最优 t 只落在端点 t∈{0,1,∞}，基本域内部网格
从不超边界最大值）。最大方向按 p 分三段：

- p < 2：**坐标向**最大（r_face, r_diag 都 < 1）；
- p = 2：各向同性，所有方向都 = π（退化，唯一不唯一）；
- 2 < p < **p\* = 4.9982155968**：**体对角向**最大；
- p > p\*：**面对角向**最大（p=1000 时 A_face/A_coord = 1.4132 → 立方体极限 √2 = 4√2/4）。

## 1. 方法（可复跑）

每条读数由 `code/exp/lpsec_core.py` 的 `area_polar` 给出：

    A_p(n) = (1/2) ∫_0^{2π} ||cosψ·u + sinψ·v||_p^{-2} dψ ,   u,v 是 n^⊥ 的正交基

积分用 tanh-sinh（双重指数）求积，面板端点取**闭式断点**：`A cosψ + B sinψ = 0`
的全部根（分量变号处，被积函数有 |ψ-ψ0|^p 型代数端点行为）与 |w_i|=|w_j| 的全部根
（p→∞ 时 O(1/p) 过渡层所在处）。h 逐次减半，最细 h=0.03125，取相邻两级之差当误差估计。

**求积核自检（exp:000003，result=supports，exit_code=0）**

| 检查 | 结果 |
|---|---|
| p=2，任意 n（含 (0.3,-0.7,0.2)、(1,-2,3)）→ π | 最大偏差 4.4e-16 |
| p=1，与八面体边缘裁剪的精确折线面积比 | 最大偏差 6.7e-16 |
| 每个 p 的坐标截面 vs 4Γ(1+1/p)²/Γ(1+2/p) | 最大相对偏差 7.0e-16 |
| 面积对平面基的旋转不变（同 n、换 u,v） | ≤ 8.9e-16 |
| p=100，1000 的坐标/体对角/面对角截面 vs 立方体精确值 4 / 3√3 / 4√2 | 偏差随 p 缩小（p=1000：6.6e-6 / 1.7e-5 / 3.9e-3，O(1/p) 量级，如实报出） |

自检过程中发现并修掉了两个**真错**（都是核的错误，不是判据放宽）：
① 断点漏了相差 π 的另一个根（收敛被卡在 1e-4）；② 立方体面对角截面参考值写成 2√2
（应为 4√2：该截面是边长 2 与 2√2 的矩形）。修前那两版实验（exp:000000/000001/000002）
已被框架按「脚本已改」撤销，exp:000005 那条是 claim 写错 + p=2 退化误判，也已撤销。

所以截面面积只依赖排序后的绝对值 (a≤b≤c) —— 这就是「模旋转与坐标置换」的正确读法；
**任意旋转不是对称**（p≠2），只有 ±坐标置换是。基本域 0≤a≤b≤c。

## 3. 临界 p（exp:000006 的 Q1/Q2 段）

- r_face = A_face/A_coord 与 r_diag = A_diag/A_coord **都在 p = 2 处穿过 1**
  （二分读数：p = 1.9999999999999991；41 点 p-扫描上两条都单调递增，r_face_monotone=true，
  r_diag_monotone=true）。所以题面要的「r(p)=A_diag/A_coord 由 <1 变 >1 的临界 p」= **2**。
- 体对角 ↔ 面对角的交叉（两者都大于坐标向时决定谁最大）：
  A_diag = A_face 于 **p\* = 4.998215596841106**（二分，区间 (4,5) 内唯一交叉；
  p=5 处差 6.5e-5，p=4 处差 3.3e-2，符号确实变号）。
- 所以「最大方向」的完整分段：p<2 坐标向；p=2 退化；2<p<4.998 体对角向；
  p>4.998 面对角向。注意 r_face 在 p>p\* 之后**大于** r_diag（p=16 时 1.3543 vs 1.2914）。

## 4. 「既非坐标向也非体对角向」的极大方向？（exp:000004 / exp:000007）

结论：**没有**。判据与读数：

- 两条弧 (1,1,t)、(0,1,t) 上（t 取 51 个值 + 端点极限），最优 t 只落在端点：
  p<2 时 (0,1,t) 的最优 t→0 即坐标向 (0,1,0)；2≤p<4.998 时 (1,1,t) 的最优 t=1
  （=体对角向）；p>4.998 时最优 t=0（=面对角向 (1,1,0)）。p=2 时整条弧是平的
  （各点面积都是 π，退化）。
- 严格中间 t 从不优于端点：例如 p=1.05 时 (1,1,t) 上 t=0.025 给 1.531908 < 端点 1.532443；
  p=8 时 t=0.975 给 5.073193 < 5.075627；p=1000 时 t=0.975 给 5.586582 < 5.652925。
- 基本域内部 20×20 + 6 轮嵌套加密的网格上，内部最好值减去边界最大值始终 < 0
  （相对超出量 −1e-3 … −1.2e-1；p=2 例外，超出量 1e-16，即退化）。

## 5. 适用范围与没做的事（如实）

- 这是**数值**证据：等级最多 `strong_conjecture`，不是定理。「最大方向只在三类端点上」
  是在 (0≤a≤b≤c) 上的网格 + 局部加密 + 两条弧的细扫描上验证的，**不是**对连续域上的
  穷举证明（连续域无法穷举 ⇒ 不给 exhaustive、不送 V 签）。
- p=1000 只是立方体极限的近似，残差 O(1/p) 已逐项报出（不当事后误差抹掉）。
- 已知解析值自检覆盖 p=2（π）、p=1（八面体 2 与 3√3/4）、p→∞（4、3√3、4√2）；
  p 在中间没有闭式可对照，那里的可信度来自求积核的 1e-15 级自洽（V1–V5）与独立
  嵌套法的粗一致性（V6，误差带 0.15，仅在平滑方向可比 —— 该方法在角点退化方向自身误差
  就有 2% 量级，已在 exp:000003 里写明）。
