## 命题

设 G 是有限群，p 是素数，n_p 表示 G 的 p-Sylow 子群的个数。则对任意一个 p-Sylow 子群 P，都有 n_p = [G : N(P)]，其中 N(P) 是 P 在 G 中的正规化子。

## 证明

设 G 是有限群，p 是素数，P 是 G 的一个 p-Sylow 子群，n_p 是 G 的 p-Sylow 子群的个数，N(P) 是 P 在 G 中的正规化子。我们要证 n_p = [G : N(P)]。

先记下两条后面要用的事实，都在这里就地推出。事实 A（轨道-稳定化子）：若有限群 Γ 作用在集合 X 上，取 x ∈ X，记 Stab(x) = {g ∈ Γ : g·x = x}，则映射 g·Stab(x) ↦ g·x 是左陪集集合 Γ/Stab(x) 到轨道 Γ·x 的良定义双射，于是 |Γ·x| = [Γ : Stab(x)]。先看良定义：若 g·Stab(x) = h·Stab(x)，即 h⁻¹g ∈ Stab(x)，则 h⁻¹g·x = x，两边左乘 h 得 g·x = h·x，故换代表不改变像。再看单射：若 g·x = h·x，则 h⁻¹g·x = x，即 h⁻¹g ∈ Stab(x)，两个左陪集相等；满射按轨道的定义直接成立。

事实 B（p-群作用的固定点同余）：若有限 p-群 Γ 作用在有限集 X 上，则 |X| ≡ |Fix_Γ(X)| (mod p)。证明：把 X 按轨道分解成不交并；长度大于 1 的轨道取一点 x，由事实 A 其长度为 [Γ : Stab(x)]，而 Stab(x) 是 Γ 的真子群，故该指数是 p 的正幂、被 p 整除；长度等于 1 的轨道恰是不动点。于是 |X| 等于 |Fix_Γ(X)| 加上若干被 p 整除的项，两边模 p 相等。

事实 C（Sylow II 的共轭性，就地推出）：若 P、Q 是两个 p-Sylow 子群，让 Q 从左作用在左陪集集合 G/P 上，规定 q·(gP) = (qg)P；这确实良定义，因为若 g′ ∈ gP 则 g′ = gh（h ∈ P），于是 qg′P = qghP = qgP。由事实 B 得 |G/P| ≡ |Fix_Q(G/P)| (mod p)；左边就是指数 [G : P]，它不被 p 整除，故不动点集不能为空，可取一个不动点 gP。不动点意味着对每个 q ∈ Q 都有 qgP = gP，即 q ∈ gPg⁻¹，所以 Q ⊆ gPg⁻¹；两者阶同为 p^k，包含关系在等阶有限群之间只能是相等，故 Q = gPg⁻¹。

现在取 P 为 G 的一个 p-Sylow 子群，让 G 经共轭作用在 Syl_p(G)（G 的 p-Sylow 子群全体，它至少含 P）上，即 g·Q = gQg⁻¹。把 P 看作这个集合里的一个点 {P}，由事实 A，它的轨道大小为 [G : Stab]，其中 Stab = {g ∈ G : gPg⁻¹ = P}；这恰是正规化子 N(P) 的定义，故轨道大小等于 [G : N(P)]。

另一方面，由事实 C，Syl_p(G) 中任取一个 Q 都与 P 共轭，即 Q 落在 P 的轨道里；因此 P 的轨道就是整个 Syl_p(G)，其大小正是 n_p。两边合起来就得到 n_p = [G : N(P)]，按轨道-稳定化子公式这正是所要的等式。
