## 命题

设 G 是有限群，p 是素数。则 G 的任意两个 p-Sylow 子群（Sylow p-subgroup）互相共轭：若 H 与 K 都是 G 的 p-Sylow 子群，则存在 g ∈ G 使得 K = gHg⁻¹。

## 证明

设 G 是有限群，P 与 Q 是 G 的两个 p-Sylow 子群，我们要证它们互相共轭。

先记下一个后面要用的事实：若有限 p-群 Γ 作用在有限集 X 上，则 |X| ≡ |Fix_Γ(X)| (mod p)，其中 Fix_Γ(X) 是被 Γ 中每个元素固定的点全体。理由是把 X 按轨道分解：每个轨道的大小等于 Γ 中某个稳定化子的指数，因而是一个 p 的幂；除不动点轨道（长度为 1）之外，轨道长度都形如 p^r（r ≥ 1），于是都被 p 整除。所有非不动点轨道的长度之和模 p 为零，只剩下不动点，故 |X| ≡ |Fix_Γ(X)| (mod p)。

现在考察 Q 在左陪集空间 G/P 上的左乘作用：对 q ∈ Q 与 gP ∈ G/P，令 q·(gP) = (qg)P。先确认它是良定义的：若 gP = g′P，则 g′ = gh（其中 h ∈ P），于是 qg′P = qghP = qgP。因为 Q 是有限 p-群而 G/P 是有限集，由上面的事实得到不动点同余 |G/P| ≡ |Fix_Q(G/P)| (mod p)。

左边 |G/P| 就是指数 [G : P]。由于 P 是 p-Sylow 子群，p 不整除 [G : P]，所以左边模 p 不为零；而右边是非负整数，故不动点集不能为空，可以取一个不动点 gP。

gP 被 Q 固定，意味着对每个 q ∈ Q 都有 qgP = gP，即 qg ∈ gP，等价于 q ∈ gPg⁻¹。因此 Q ⊆ gPg⁻¹。另一方面 Q 与 gPg⁻¹ 的阶都等于 |P|，阶相同的有限群之间的包含关系只能是相等，故 Q = gPg⁻¹。

因此 G 的任意两个 p-Sylow 子群互相共轭。
