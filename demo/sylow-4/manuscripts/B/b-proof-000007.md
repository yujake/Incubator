# B 的证明手稿：Sylow 第二定理

- 标签：Sylow 第二定理

## 命题

设 G 是有限群，p 是素数。则 G 的任意两个 p-Sylow 子群（Sylow p-subgroup）互相共轭：若 H 与 K 都是 G 的 p-Sylow 子群，则存在 g ∈ G 使得 K = gHg⁻¹。

## 证明

设 G 是有限群，P 与 Q 是 G 的两个 p-Sylow 子群，我们要证它们互相共轭。

为此考察 Q 在左陪集空间 G/P 上的左乘作用：对 q ∈ Q 与 gP ∈ G/P，令 q·(gP) = (qg)P。因为 Q 是有限 p-群而 G/P 是有限集，这个作用满足不动点同余 |G/P| ≡ |Fix_Q(G/P)| (mod p)，其中 Fix_Q(G/P) 是被 Q 中每个元素固定的那些陪集。

左边 |G/P| 就是指数 [G : P]。由于 P 是 p-Sylow 子群，p 不整除 [G : P]，所以左边模 p 不为零，于是不动点集不能为空，可以取一个不动点 gP。

gP 被 Q 固定，意味着对每个 q ∈ Q 都有 qgP = gP，即 qg ∈ gP，等价于 q ∈ gPg⁻¹。因此 Q ⊆ gPg⁻¹。另一方面 Q 与 gPg⁻¹ 的阶都等于 |P|，包含关系在阶相同的有限群之间只能是相等，故 Q = gPg⁻¹。

因此 G 的任意两个 p-Sylow 子群互相共轭。
