## 命题

设 G 为有限群，|G| = p^a·m，其中 p 是素数，a ≥ 0、m ≥ 1 是整数，且 p 不整除 m。记 n = p^a。则 (E) G 存在阶为 n 的子群；(C) 若 P、Q 是 G 的两个阶为 n 的子群，则存在 g ∈ G 使 Q = gPg⁻¹；(N) 若 n_p 表示 G 的阶为 n 的子群个数，则 n_p ≡ 1 (mod p) 且 n_p 整除 m。

## 证明

1. 前提与记号。设 G 是有限群，|G| = p^a·m，其中 p 是素数，a ≥ 0 与 m ≥ 1 是整数，且 p 不整除 m。记 n = p^a，称 G 的阶为 n 的子群为 p-Sylow 子群，记其个数为 n_p。本步把下列约定声明为全篇前提：群的定义、子群的定义、有限集基数的基本性质、以及 |G| = p^a·m 与 p ∤ m。除此之外不使用任何未在本稿内证明的事实：下文事实 1 至事实 8 各自带完整推导，且每一步只引用它之前已经写出的句子。（前提）
2. 事实 1（左陪集分解与 Lagrange 定理）。设 A 是有限群，B ≤ A。在 A 上定义 a ~ b 当且仅当 a⁻¹b ∈ B。这是等价关系：自反性是 a⁻¹a = e ∈ B；对称性由 a⁻¹b ∈ B 推出 b⁻¹a = (a⁻¹b)⁻¹ ∈ B（B 对取逆封闭）；传递性由 a⁻¹b ∈ B 与 b⁻¹c ∈ B 推出 a⁻¹c = (a⁻¹b)(b⁻¹c) ∈ B（B 对乘法封闭）。含 a 的等价类恰是左陪集 aB：b ~ a 当且仅当 a⁻¹b ∈ B 当且仅当 b ∈ aB。左乘给出从 B 到 aB 的双射 b ↦ ab（逆映射为 x ↦ a⁻¹x），故 |aB| = |B|。A 是两两不交的左陪集之并，设左陪集个数为 [A:B]，则 |A| = |B|·[A:B]。特别地 |B| 整除 |A|，且 [A:B] = |A|/|B|。又若 B ≤ C ≤ A，则把 A 按右陪集分成 C 的陪集、再把每个 C 陪集按 B 的陪集分块，得 [A:B] = [A:C]·[C:B]。（前提）
3. 事实 2（轨道分解与轨道-稳定化子）。设有限群 Γ 作用在集合 X 上。对 x ∈ X 记轨道 Γ·x = {g·x : g ∈ Γ}，稳定化子 Stab(x) = {g ∈ Γ : g·x = x}。Stab(x) 是 Γ 的子群：e·x = x；若 g·x = x 与 h·x = x 则 (gh)·x = g·(h·x) = g·x = x；若 g·x = x 则 g⁻¹·x = g⁻¹·(g·x) = (g⁻¹g)·x = x。两个轨道若相交则相等：若 z = g·x = h·y，则对任意 g' 有 g'·x = (g'g⁻¹h)·y ∈ Γ·y。故 X 是轨道的不交并。映射 φ 把左陪集 g·Stab(x) 送到 g·x 是良定义的双射：若 g·Stab(x) = h·Stab(x) 则 h⁻¹g ∈ Stab(x)，故 g·x = h·x；反之若 g·x = h·x 则 h⁻¹g·x = x，故 h⁻¹g ∈ Stab(x)，两个左陪集相等；满射按轨道定义成立。由事实 1，|Γ·x| = [Γ:Stab(x)] = |Γ|/|Stab(x)|，特别地轨道长整除 |Γ|。（前提）
4. 事实 3（p-群作用的固定点同余）。设 Γ 是有限 p-群，即 |Γ| = p^s（允许 s = 0，此时 Γ 是平凡群），Γ 作用在有限集 X 上。记 Fix_Γ(X) = {x ∈ X : 对每个 g ∈ Γ 都有 g·x = x}。断言 |X| ≡ |Fix_Γ(X)| (mod p)。证明：由事实 2，X 是轨道的不交并。长度等于 1 的轨道恰由固定点组成，即 Fix_Γ(X)。设某轨道长度大于 1 并取其中一点 x，则 Stab(x) ≠ Γ（否则该轨道长度为 1），由事实 1 与事实 2 得该轨道长度 = |Γ|/|Stab(x)| = p^t 且 t ≥ 1（Stab(x) 是 Γ 的真子群，其阶与指数都是 p 的正幂），从而该轨道长度被 p 整除。于是 |X| 等于 |Fix_Γ(X)| 加上若干被 p 整除的整数，同余式成立。s = 0 时 Γ 只有单位元，Fix_Γ(X) = X，同余式以等号成立。（前提）
5. 事实 4（Cauchy 定理，McKay 计数证明）。设 A 是有限群，p 是素数且 p 整除 |A|。断言 A 含有阶为 p 的元素。证明：令 X = {(a_1,…,a_p) ∈ A^p : a_1a_2⋯a_p = e}。给定前 p−1 个坐标，最后一个坐标被唯一确定为 (a_1⋯a_(p−1))⁻¹，故 |X| = |A|^(p−1)；因 p 整除 |A| 且 p−1 ≥ 1，故 p 整除 |X|。让 p 阶循环群 C_p = ⟨σ⟩ 作用在 X 上：σ·(a_1,…,a_p) = (a_2,…,a_p,a_1)。先验这是良定义的作用。① X 对移位封闭：设 a_1a_2⋯a_p = e，令 b = a_2⋯a_p，则 a_1b = e，两边左乘 a_1⁻¹ 得 b = a_1⁻¹；于是移位后的乘积 a_2⋯a_p a_1 = b·a_1 = a_1⁻¹a_1 = e，故 (a_2,…,a_p,a_1) ∈ X（这一步只用到结合律与逆元的定义，没有用到交换性）。② σ^p 是恒等映射：连续移位 p 次把每个坐标送回原位。③ 幂作用相容：σ^i·(σ^j·x) 与 σ^(i+j)·x 都把 x 的第 k 个坐标移到第 k+i+j 个位置（下标模 p），故相等。于是 C_p 作用在 X 上。X 的不动点满足 (a_1,…,a_p) = (a_2,…,a_p,a_1)，即坐标全相等的元素 (a,…,a)，而条件 a_1⋯a_p = e 此时变为 a^p = e；故 Fix_(C_p)(X) 与 {a ∈ A : a^p = e} 基数相同。由事实 3（|C_p| = p 是 p-群）得 |{a ∈ A : a^p = e}| ≡ |X| ≡ 0 (mod p)。单位元满足 a^p = e，故该集合非空，其基数被 p 整除，于是至少含 p 个元素，从而存在 a ≠ e 且 a^p = e；a 的阶整除 p 且不为 1，故为 p。（前提）
6. 事实 5（共轭类与类方程）。设 A 是有限群，Z(A) 记中心。对 a ∈ A 记中心化子 C_A(a) = {g ∈ A : gag⁻¹ = a}。关系「a 与 b 共轭」（存在 g 使 b = gag⁻¹）是等价关系：自反性取 g = e；对称性由 b = gag⁻¹ 得 a = g⁻¹bg；传递性由 b = gag⁻¹ 与 c = hbh⁻¹ 得 c = (hg)a(hg)⁻¹。A 经共轭作用在自身上（g·a = gag⁻¹），共轭类就是轨道，a 的稳定化子正是 C_A(a)（g·a = a 等价于 gag⁻¹ = a）。由事实 2，a 的共轭类长度等于 [A:C_A(a)]。a 属于 Z(A) 当且仅当它的共轭类只含 a 自身。取全部非中心共轭类的代表元 x_1,…,x_r，则 A 是 Z(A) 与这些共轭类的不交并，于是 |A| = |Z(A)| + Σ_(i=1..r) [A:C_A(x_i)]。又每个 x_i 不在中心，故 C_A(x_i) 是 A 的真子群，由事实 1 得 [A:C_A(x_i)] > 1 且整除 |A|。（前提）
7. 事实 6（强归纳假设）。本稿对有限群的阶做强归纳，所断言的命题是：对任意有限群 A 与素数 q，若 q^b 是 |A| 的 q-部分（即 |A| = q^b·m' 且 q 不整除 m'），则 A 有阶为 q^b 的子群。本步把「该断言对所有满足 |A| < |G| 的有限群 A 成立」声明为归纳前提；下文 (E) 的证明将以它为依据，并且总在比 G 更小的群（真子群或真商群）上使用它。（前提）
8. 事实 7（p-Sylow 子群的正规化子）。设 P ≤ G 且 |P| = p^a —— 本步的前提是 |P| = p^a（P 是 G 的 p-Sylow 子群），而不是「P 是任意子群」。记 N_G(P) = {g ∈ G : gPg⁻¹ = P}。它是 G 的子群：e ∈ N_G(P)；若 g, h ∈ N_G(P) 则 (gh)P(gh)⁻¹ = g(hPh⁻¹)g⁻¹ = gPg⁻¹ = P；若 g ∈ N_G(P) 则 g⁻¹Pg = g⁻¹(gPg⁻¹)g = P。又对每个 p_0 ∈ P 有 p_0Pp_0⁻¹ = P（左乘 p_0 把 P 双射到自身），故 P ≤ N_G(P)。由事实 1，|P| 整除 |N_G(P)|，且 |N_G(P)| 整除 |G|。代入 |P| = p^a 与 |G| = p^a·m 得 |N_G(P)| = p^a·d，其中 d 是正整数且 d 整除 m；由于 p ∤ m 且 d | m，得 p ∤ d，于是 p^a 整除 |N_G(P)| 且恰是 |N_G(P)| 的 p-部分。又由事实 1，[N_G(P):P] = |N_G(P)|/|P| = d，故 [N_G(P):P] 整除 m 且与 p 互素。（前提）
9. (E) 的证明，情形一：a = 0。此时 n = p^0 = 1。平凡子群 {e} 是 G 的子群且阶为 1 = n，故 (E) 成立。附带说明此情形下的唯一性：若 H ≤ G 且 |H| = 1，则 H = {e}，故阶为 1 的子群只有平凡子群一个。（前提）
10. (E) 的证明，情形二：a ≥ 1 且存在真子群 H < G 使 p^a 整除 |H|。此时 |H| < |G|；又由事实 1，|H| 整除 |G| = p^a·m，故 |H| = p^a·m_1 且 m_1 整除 m，于是 p^a 恰是 |H| 的 p-部分（因 p ∤ m 从而 p ∤ m_1）。由事实 6（归纳假设，|H| < |G|）H 有阶为 p^a 的子群 K；子群的子群仍是 G 的子群，故 K 是 G 的阶为 p^a 的子群，(E) 成立。（前提）
11. (E) 的证明，情形三的先导计算：a ≥ 1 且每个真子群 K < G 都满足 p^a 不整除 |K|。先证 p 整除 |Z(G)|。由事实 5 的类方程 |G| = |Z(G)| + Σ_(i=1..r) [G:C_G(x_i)]，其中 x_i 取遍非中心共轭类的代表元。对每个 i，x_i 不在中心，故 C_G(x_i) 是 G 的真子群，由本情形的假设 p^a 不整除 |C_G(x_i)|；又由事实 1，|C_G(x_i)| 整除 |G| = p^a·m，故 |C_G(x_i)| 的 p-部分为 p^(b_i) 且 b_i ≤ a−1，于是 [G:C_G(x_i)] = |G|/|C_G(x_i)| 的 p-部分为 p^(a−b_i) 且 a−b_i ≥ 1，即 p 整除 [G:C_G(x_i)]。又 a ≥ 1，故 p 整除 |G| = p^a·m。于是把类方程两边模 p 得 0 ≡ |Z(G)| (mod p)，即 p 整除 |Z(G)|。（前提）
12. (E) 的证明，情形三的主论证（续情形三）。由上一步：若 G 非交换，则 p 整除 |Z(G)|，对有限群 Z(G) 用事实 4（Cauchy 定理）得存在 z ∈ Z(G) 其阶为 p；若 G 交换，则 Z(G) = G 且 p 整除 |G| = p^a·m，由事实 4 得存在 z ∈ G = Z(G) 其阶为 p。两种情形都得到阶为 p 的中心元 z。令 N_0 = ⟨z⟩ = {z^j : 0 ≤ j ≤ p−1}，由 z 的阶为 p 得 |N_0| = p。因 z ∈ Z(G)，对任意 g ∈ G 有 gN_0g⁻¹ = ⟨gzg⁻¹⟩ = ⟨z⟩ = N_0，故 N_0 是 G 的正规子群。下面就地推出商群与纤维计数，只用到事实 1 与群的定义，不引用第一同构定理。(a) 商群：在左陪集集合 G/N_0 = {gN_0 : g ∈ G} 上定义乘法 (gN_0)(hN_0) := ghN_0。良定义：若 gN_0 = g'N_0 且 hN_0 = h'N_0，则 g' = gn_1、h' = hn_2，其中 n_1, n_2 ∈ N_0；由 N_0 正规，h⁻¹n_1h ∈ N_0，于是 g'h' = gn_1hn_2 = gh(h⁻¹n_1h)n_2 ∈ ghN_0，故 g'h'N_0 = ghN_0。结合律由 G 的结合律得到；单位元是 N_0 = eN_0；gN_0 的逆元是 g⁻¹N_0。故 G/N_0 是群。由事实 1，|G/N_0| = [G:N_0] = |G|/|N_0| = p^a·m/p = p^(a−1)·m。(b) 商映射 π: G → G/N_0，π(g) = gN_0 是同态：π(gh) = ghN_0 = (gN_0)(hN_0) = π(g)π(h)，且 π(e) = N_0 是 G/N_0 的单位元。(c) 因 a ≥ 1 得 |G/N_0| = p^(a−1)·m < p^a·m = |G|，且 p 不整除 m，故 p^(a−1) 是 G/N_0 的 p-部分；由事实 6（归纳假设）存在 G/N_0 的阶为 p^(a−1) 的子群 H̄。令 H = π⁻¹(H̄) = {x ∈ G : π(x) ∈ H̄}。H 是 G 的子群：由 π(e) = N_0 ∈ H̄ 得 e ∈ H；若 x, y ∈ H 则 π(xy) = π(x)π(y) ∈ H̄，故 xy ∈ H；若 x ∈ H 则 π(x⁻¹) = π(x)⁻¹ ∈ H̄，故 x⁻¹ ∈ H。又 N_0 ≤ H：对 n ∈ N_0 有 π(n) = nN_0 = N_0 ∈ H̄，故 n ∈ H。(d) 对每个 ḡ ∈ H̄ 取 g ∈ H 使 π(g) = ḡ（由 H 的定义这样的 g 存在），断言 H 中满足 π(x) = ḡ 的 x 全体恰为 gN_0：若 x ∈ H 且 π(x) = π(g)，则 π(g⁻¹x) = π(g)⁻¹π(x) = N_0，即 g⁻¹x ∈ N_0，故 x ∈ gN_0；反之若 x = gn 而 n ∈ N_0，则由 g ∈ H 与 N_0 ≤ H 得 x ∈ H，且 π(x) = π(g)π(n) = ḡ·N_0 = ḡ。不同的 ḡ 对应的这些集合两两不交，并集为 H（每个 x ∈ H 落在 ḡ = π(x) 那一块），且每一块与 N_0 基数相同（左乘 g 给出从 N_0 到 gN_0 的双射，见事实 1 的证明）。于是 |H| = |H̄|·|N_0| = p^(a−1)·p = p^a。故 (E) 成立。（前提）
13. (E) 的小结。对 |G| 作强归纳：a = 0 由情形一处理；a ≥ 1 时，要么存在真子群 H < G 且 p^a 整除 |H|，由情形二并借助归纳假设处理；要么每个真子群 K < G 都满足 p^a 不整除 |K|，由情形三处理（类方程给出 p 整除 |Z(G)|，Cauchy 定理给出中心里阶 p 的元素 z，商去正规子群 ⟨z⟩ 后由归纳假设得到阶 p^(a−1) 的子群，其原像阶为 p^a，原像的阶按第 12 步 (d) 的纤维计数得出）。这三种情形穷尽了所有可能，故 G 存在阶为 n = p^a 的子群，(E) 成立。（前提）
14. 事实 8（p-Sylow 子群在陪集上的固定点计数）。设 P ≤ G 且 |P| = p^a（同样以 |P| = p^a 为前提）。让 P 通过左乘作用在左陪集集合 G/P 上：x·(gP) = (xg)P。这是作用：e·(gP) = gP；x·(y·(gP)) = (xy)·(gP)；且 (xg)P 只依赖 gP（若 gP = g'P 则 g' = gb，b ∈ P，于是 xg'P = xgbP = xgP）。由事实 1，|G/P| = [G:P] = |G|/|P| = m。计算不动点：gP ∈ Fix_P(G/P) 当且仅当对每个 x ∈ P 有 xgP = gP 当且仅当对每个 x ∈ P 有 g⁻¹xg ∈ P 当且仅当 g⁻¹Pg ⊆ P；由于 g⁻¹Pg 与 P 是基数相同的有限集，「g⁻¹Pg ⊆ P」等价于 g⁻¹Pg = P，即 g ∈ N_G(P)。故 Fix_P(G/P) = {gP : g ∈ N_G(P)}，把 N_G(P) 按 P 的右陪集分块即知它的基数等于 [N_G(P):P]。由事实 3（|P| = p^a 是 p 的幂）得 m = |G/P| ≡ [N_G(P):P] (mod p)。（前提）
15. (C) 的证明。设 P 与 Q 是 G 的任意两个 p-Sylow 子群，即 |P| = |Q| = p^a（这类子群存在已由 (E) 给出）。让 Q 通过左乘作用在 G/P 上，如事实 8 的做法。由事实 3，|Fix_Q(G/P)| ≡ |G/P| = m (mod p)。因 p 不整除 m，故 |Fix_Q(G/P)| 不被 p 整除，特别地 Fix_Q(G/P) 非空。取 gP ∈ Fix_Q(G/P)，则对每个 x ∈ Q 有 xgP = gP，即 g⁻¹xg ∈ P，故 g⁻¹Qg ⊆ P；又 |g⁻¹Qg| = |Q| = p^a = |P| 且两者都是有限集，故 g⁻¹Qg = P，等价地 Q = gPg⁻¹。因此任两个 p-Sylow 子群共轭，(C) 成立。（前提）
16. (N) 的证明，第一部分：n_p 整除 m。G 经共轭作用在自身的子群集合上：g·H = gHg⁻¹。这是作用（e·H = H；(gh)·H = (gh)H(gh)⁻¹ = g(hHh⁻¹)g⁻¹）。P 的轨道是 {gPg⁻¹ : g ∈ G}，由 (C) 它恰是 G 的全体 p-Sylow 子群，故轨道长度等于 n_p；P 的稳定化子是 {g : gPg⁻¹ = P} = N_G(P)。由事实 2，n_p = [G:N_G(P)] = |G|/|N_G(P)|。由事实 7，|N_G(P)| = p^a·d 且 d 整除 m，故 n_p = (p^a·m)/(p^a·d) = m/d，特别地 n_p 整除 m。（前提）
17. (N) 的证明，第二部分：n_p ≡ 1 (mod p)。沿用事实 7 与事实 8 的记号 d = [N_G(P):P] = |N_G(P)|/p^a。由事实 8 有 m ≡ d (mod p)；由上一步有 m = n_p·d。两式合并得 n_p·d ≡ d (mod p)，即 (n_p − 1)·d ≡ 0 (mod p)。由事实 7，d 整除 m 且 p ∤ m，故 p ∤ d，于是 n_p ≡ 1 (mod p)。结合 (E)（情形一至情形三及小结）、(C) 与 (N) 的两部分，(E)(C)(N) 三条断言全部得证。（前提）
