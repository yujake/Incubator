# 攻坚计划 000000 — 进展台账（猜想 conjectures:000000）

限定（任何一条结论都必须带这一句）：δ_0 不是因子不变量，下面所有量只对**标准自由生成元元组** X_k=(u_1,…,u_k)（u_i 为 W*(F_k) 的标准自由生成元）定义；文献里 δ(W*(F_k))=k 只是猜想，本文件任何读数都**不是证明**，最高只到 supported_not_proved。

## 轮 1 · sg-a（owner=F）：δ_N(X_k) 的可复现确定性口径与可行性判定

状态：口径已写成（见下 §A1–§A4）；可行性判定=**字面口径在 N≥16 上不可行**（§A5，给出理由的定量估计）。依据：无实验行（这一条不产生 experiment_ids，是定义/可行性判定）。

### A1 估计量定义（字面口径，E1）

对 k 元组 V=(v_1,…,v_k)∈U(N)^k，取 2-范数（Hilbert–Schmidt 归一）
  d_2(V,W) = ( (1/(k N)) Σ_i Tr((v_i-w_i)*(v_i-w_i)) )^{1/2}
微态测度 μ_N = (Haar on U(N))^{⊗k}。定义球
  B_r(X) = { V : d_2(V, X) ≤ r }，X 取标准元组的 N 阶近似（见 A2）。
有限截断估计量：
  δ_N(r) = log μ_N(B_r(X)) / ( N^2 · log r )，  r∈(0,1)（分子分母同为负，比值为正）
  拟合口径：固定 r=2^{-j}, j=4..8，按 δ_N(r) = δ_N(∞) − β·(1/|log r|) 外推 1/|log r|→0 得 δ_N。
参数（固定，不许在一次比较内变动）：k∈{2,3,4}；N∈{8,16,32,64}；种子 seed=20261018（每档同一 seed，逐档加 k*100+N 派生）；每档 MC 样本 M=200000；收敛判据：分 10 批递进，相邻两批 δ_N 估计的相对变化 <0.02 且最后两批的 95% 二项 CI 半宽 <0.05·|δ_N|。

### A2 标准元组的 N 阶近似（确定性、可复现）

X_k 的 N 阶实现取"自由 Haar 元组"的确定性构造：固定 seed 生成 k 个独立 N×N Ginibre 复高斯矩阵 G_i，QR 分解取 Q_i（对角相位按 Harish-Chandra 约定归一，保证对 Haar 测度不变），V_i = Q_i。这一步**不**依赖任何模型判断，全过程由 seed 唯一确定。

### A3 输出（E 的脚本必须逐行打印）

每个 (k,N)：δ_N(r) 的五个 j 值、外推 δ_N、每批计数 n_hit、MC 样本数、95% CI、运行时长（秒）、是否达 A1 的收敛判据（bool）。全部写进 experiments 行（method='numeric'，固定 seed，附脚本 sha256）。

### A4 支撑/反对的读数（预先写定，防事后改口径）

- ① δ_N(X_k) ≥ k − C/log N：对每个 k 拟合 C_k（用 N∈{8,16,32,64} 四点做 δ_N = k − C/log N 的最小二乘），报告 C_k 与残差；"C 与 k 无关"判据：max C_k − min C_k ≤ 拟合残差的最大值。
- 判定档位只有三档：支持（supported_not_proved）/ 反驳 / 数据不足（含估计量本身不可行的情形）。

### A5 可行性判定（本轮的实际结论）

μ_N(B_r) ≈ r^{k N^2} 量级（k 个自由生成元共 kN^2 个实自由度）；取 r=2^{-8}、k=2、N=16：log μ ≈ −2·256·8·ln2 ≈ −2839，即概率 ~e^{-2839}。M=2×10^5 的 MC 一个命中都拿不到（要 ~e^{2839} 个样本）。因此：
- N=8, k=2：r^{kN^2}=2^{-128} 仍不可行；
- 结论：**字面口径 E1 在 N∈{8,16,32,64} 全部不可行**，不是"需要更多算力"，是需要重要性采样/变分构造在 B_r 内直接生成微态（那是另一条研究路线，本轮未接线）。
- 由此：猜想 000000 的 ① 与 ② 若要求"沿 N 截断序列直接估计 δ_N"，在当前 E 的可执行面上**做不了**；只能走 A6 的替代口径，且替代口径的读数**不能**直接判 ①/② 的真假（它只是必要条件的检验）。

### A6 替代口径（E2，唯一可让 E 跑的路线；必须带 caveat）

不用体积，用"矩/累积量缺陷"作为代理量：对 A2 生成的元组，计算长度 ≤4 的字的归一迹 τ_N(w) 与自由 Haar 预测值（非交换累积量口径）的偏差
  D_N(L) = max_{|w|≤L} |τ_N(w) − τ_free(w)|，L=4。
可判定的读数：D_N 随 N 的衰减率（拟合 D_N ≈ a·N^{-θ}）。用途仅限：若 D_N 不随 N 衰减，则说明 A2 的采样都没落在标准元组的微态邻域里，① 的数值检验无从谈起；若衰减，也不构成对 ① 的支持（D_N 与 δ_N 之间没有已证的桥）。这正是本条要写清的限定。
