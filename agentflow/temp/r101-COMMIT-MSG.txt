## 一、新读数 `secretary.reach_fit(role, action)`

`surface_fit` 判的是**路径面**（这句话里的文件落不落在它的沙箱里）；`reach_fit` 判的是
**能力面**：那个动作，被派人自己有没有？没有的话，它出边上的伙伴（再由伙伴的出边……
直到 `policy.Policy().max_depth`）里有谁有、走哪几跳？四档：

| 档 | 意思 |
|---|---|
| `in_self` | 被派人自己的动作表里就有（一跳都不用） |
| `via_edges` | 靠出边上的伙伴，`hops` 给出那条链 |
| `unreachable` | 它那一支闭包里没有任何人有 ⇒ **面内做不成**（改派 / 走上报那一档） |
| `unknown` | 角色或动作名认不出 ⇒ 判不了（**不许折成"做得到"**） |

深度上限取 `policy.Policy().max_depth`（唯一来源），不另带一份。

## 二、真表读数（本机实跑）

```
H  judge_quote_semantics  in_self      ['H']
B  judge_quote_semantics  via_edges    ['B', 'H']          ← 新设计那条边
B  verify_proof           via_edges    ['B', 'V']
A  build_document         via_edges    ['A', 'B', 'H', 'G'] ← 三跳；只看自己会漏掉
C  run_experiment         unreachable  ['C']               ← C 没有出边，闭包只有它自己
M  judge_quote_semantics  via_edges    ['M', 'H']
谁 x / B 没这个动作        unknown      （各带一句为什么）
```

## 三、判据（新文件 `tests/test_secretary_reach_fit.py`，5 条）

四档齐全；`B → H` 一跳那条（**这是新设计本身的回归守卫**：边或动作掉了当场红）；
`A → B → H → G` 三跳那条（证明闭包真的按出边走，而不是只看被派人自己）；
`C` 那一支 `unreachable`（并先断言 `ALLOWED_EDGES["C"]` 是空集，免得判据的前提漂掉）；
认不出的角色 / 动作 / 空动作名各给 `unknown` + 一句为什么。
