# 攻坚：一次一步，每一步留得下中间态

- 名字：`攻坚-一次一步并留中间态`
- 属于：`F`
- 什么时候读它：被派一条要证的命题，或一条计划要往前推一轮的时候
- 一句话：先立项（预算不完整即拒）；step 是唯一会改计划的方法；一轮一步
- 会用到的动作（角色.动作）：F.create_plan, F.step, F.status
- 会用到的工具：attack.create_plan, attack.pick_next_subgoal, attack.check_budget

# 攻坚：一次一步

## 立项（`F.create_plan`）

**预算不完整即拒绝，且不写库** —— 被拒是受控的：补齐预算再立一次，
别把"没立成"当成"不需要立"。

预算**四类键缺一不可**（2026-10-16 亲测记下，FC-18）：`max_rounds`、
`max_parallel_subgoals`、`max_persist_attempts`、`max_depth`。
只有轮数上限 ⇒ 单轮可无限扇出；只有并发上限 ⇒ 可无限轮。

子目标**每一项三格必填**（少一格就被拒，而且**整笔不写库**）：

| 键 | 意思 |
|---|---|
| `sid` | 这一项的编号（计划内部用） |
| `text` | **要做什么**（一句话说清；写成 `goal` 不算） |
| `owner` | 归谁做（**权限面的一部分，不能默认**） |

`status` 可给可不给，词表是 `todo` / `in_progress` / `supported_not_proved` /
`closed` / `blocked` / `dropped`（写错会被拒，且拒信里会列出词表）。

## 推进（`F.step`）

`F.step` 是**唯一会改计划的方法**（`list_plans` / `status` 只读）。
一轮一步：一轮里塞三件事，出错时你不知道是哪一步坏的。

## 中间态必须留得下（这一条最容易被省）

每一步的产出要能**被别人复核**：把一个中间结论写成命题（交 **B** 登记，
`F → B` 是直接边）或写成盘上的文件（`fs.write`），而不是只在话里说"我证到了这一步"。
理由：复核的人（**V**）是**冷启动**的 —— 它只看证明本身，不看你的心路。

## 一条路不通时：先记下试过哪几条，再换

同一个子目标**同时想几条路**（直接证 / 反证 / 归纳 / 归约到一条已知结论 / 改写一条已知论证），
一条走不通就换下一条 —— 但换之前先把"这条路卡在哪"写进盘上那一行：
**把同一份证明再抄一遍不是换路**，而"我换了思路"不写下来，下一趟的人只会重走第一条。

**什么时候才允许自己造新办法**：上面那几条都试过、且卡点说得清（缺哪条引理、哪一步的界
对不上、哪条假设用不上）之后。造出来的办法要回头套回**当前这个子目标**上验一遍；
验不过就如实记"造了、没成" —— 那也是一条留给下一趟的读数。

## 卡住时

先 `F.status` / `F.list_plans` 读当前状态，再说卡在哪一步、缺什么。
"看不出来"是合法的三态之一，但它必须指到那一步。
