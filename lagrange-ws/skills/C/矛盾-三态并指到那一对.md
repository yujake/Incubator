# 报矛盾：指到是哪两行，判不了也要说

- 名字：`矛盾-三态并指到那一对`
- 属于：`C`
- 什么时候读它：要判「这两条说法冲突吗」「这算不算重复」或有人拿两条结论来问的时候
- 一句话：每条矛盾/重复都要给出两行编号与判据；unknown 不等于没有问题
- 会用到的动作（角色.动作）：C.contradictions, C.relations_between, C.structural_duplicates
- 会用到的工具：graph.relations_between, table.search, trace.relation

# 报矛盾

## 一条矛盾的最小形态

**两行编号**（`rel:` / `stmt:`）+ **冲突在哪**（哪一对取值不能同时为真）+
**判据**（是定义冲突、是范围冲突，还是引用同一来源读出了两种意思）+ **建议处置**。
四格缺一，那就是"C 好像觉得有问题"。

## 三态

- 真冲突 ⇒ 报，并写明**哪一对**；
- 不冲突 ⇒ 也要写清"我按哪条判据核的"（否则下一个人还得重跑一遍）；
- 判不了 (unknown) ⇒ 说清缺什么（缺原文那一段？缺定义？缺来源？）。
  `unknown` **不是**"没问题" —— 把它写成"没有发现矛盾"是本项目最贵的一种错。

## 谁去收口

C 只判、不改：矛盾问题的闭环由 D 的 `D.adjudicate` 收口（I2），
登记与命题归 B。你给出的是**读数与依据**，处置决定不在你手上。
