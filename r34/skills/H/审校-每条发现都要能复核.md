# 审校：每条发现都要指到那一行、并给出最小修法

- 名字：`审校-每条发现都要能复核`
- 属于：`H`
- 什么时候读它：做 review / review_report，或收到「这几处改了吗」的复核请求时
- 一句话：发现必须带轴/严重度/行号/逐字引文/最小修法 —— 光说「有问题」不算
- 会用到的动作（角色.动作）：H.review, H.verify_fixes, A.run_once
- 会用到的工具：manuscripts.read, table.list

# 审校

## 一条发现的最小形态

**轴**（体例 / 数学 / 引用 / 结构）· **严重度**（error / warning / info）·
**行号** · **逐字引文**（≤20 词，从正文里抄，不是转述）· **最小修法**。
五格缺一，这条发现就是"审校者的印象"，而不是可复核的读数 ——
真机里出现过"评审方提的 medium 泄漏是错的，实现方拿证据顶回来"这种事，
所以发现本身也要能被顶。

## 两档别混

- `H.review`：**审稿** —— 出 findings（落 `review_findings`）；
- `H.review_report`：**审报告** —— 判一份报告站不站得住（体例与承重）。
一次只做一件；两件放一起会让"这是稿子的问题还是报告的问题"读不出来。

## 引文那一档

拿不准逐字对不上算不算错，用 `H.judge_quote_semantics` 判**语义**（四档结论：
`same_meaning` / `different` / `stronger_than_source` / `unjudgeable`）。
"比原文更强"（`stronger_than_source`）是数学写作里最常见的隐性缺陷：
原文有条件、正文里没了 —— 这一档必须指出来。

### 判之前先看**两个前置**（2026-10-16 亲测：两次都如实"没判成"，都没猜）

```
① `quote`（待核引文）与 `span`（来源里那一段）**都必须给**
   ⇒ 缺任一：verdict='unknown'、tri='unreadable'、"少了任何一条，这一档无从判起（没查，不是通过）"
② 判定要**接上模型**：裸装配下 ⇒ verdict='unknown'、reason='judge_not_wired'
   "没有接模型（或没有 key）：这是没判成，不是判过了没问题"
```

⇒ 读到 `unknown` 时**先看是哪一种**：材料不全就补齐再判；没接模型就**换句话说**去问
（或如实记成"这一档没判"）—— **别把 `unknown` 读成"通过了"**。

## 审报告落在哪、返回什么（2026-10-16 亲测）

`H.review_report(doc_id)` **真的落盘**：`out/review/<doc_id>-review.md`；
返回里**同时给** `markdown`（报告全文）与 **`report_path`**（落盘路径）——
所以"报告在哪"不用猜，读 `report_path` 就行。它需要的轮次参数是**关键字** `round_no`
（位置传会报 `takes 2 positional arguments but 3 were given`）。

## 复核修法

别人说"改了"，用 `H.verify_fixes` 逐条核**改没改对**，而不是重头再审一遍。

## 论文对应表：逐行核，别只看"有没有"

拿到论文稿先读 `out/paper/MAPPING.json`（人读那份 `out/paper/MAPPING.md` 由它生成），
再**逐行**核：正文里每个定理类环境在表里有没有一行、表里每一行在正文里有没有那个环境
（label 与 `env_no` 都要对）、`ledger_id` 与 `proof_no` 能不能在台账里解析到、`file`
指向的那份文件在不在论文包里、正文附录「附录：产出对应表」与 json 渲染出来的是否逐字一致。
这一档是**客观问题（可拦）**：判出来就写成 error 级发现，kind 用
`mapping_package_missing` / `mapping_missing` / `mapping_orphan` / `mapping_unresolvable` /
`mapping_file_missing` / `mapping_citation_loc_missing` / `mapping_citation_file_missing` /
`md_missing` / `md_drifted` / `mapping_not_in_paper` / `mapping_paper_mismatch` 之一。
**逻辑颠倒、缺铺垫、术语没定义、承诺未回应、交叉引用错这一档是主观问题：点名到句，
不拦门**——别把品味判成 error。
