## §PROOF
命题：设 G 是有限群，|G| = 96 = 2^5·3。若 n_3(G) = 1 且 n_2(G) = 1，则 G ≅ P × C_3，其中 P 是 G 的（唯一）Sylow 2-子群。

证明。
(1) 因 n_3(G) = 1，Sylow 3-子群唯一，记之为 Q，则 Q ⊴ G 且 |Q| = 3。因 n_2(G) = 1，Sylow 2-子群唯一，记之为 P，则 P ⊴ G 且 |P| = 32。
(2) Q ∩ P 同时是 Q 与 P 的子群，故 |Q∩P| 整除 |Q| = 3 与 |P| = 32，而 gcd(3,32) = 1，故 |Q∩P| = 1，即 Q ∩ P = {1}。
(3) 由乘积公式 |PQ| = |P||Q| / |P∩Q| = 32·3/1 = 96 = |G|，又 PQ ⊆ G，故 PQ = G。
(4) 因 P ⊴ G，对任意 p ∈ P、q ∈ Q 有 [p,q] = p q p^{-1} q^{-1} ∈ P（前三个因子在 P 中，P 正规使 q^{-1} 共轭 p q p^{-1} 回 P... 更直接：P ⊴ G ⇒ [P,Q] ≤ P）；因 Q ⊴ G ⇒ [P,Q] ≤ Q。故 [P,Q] ≤ P ∩ Q = {1}，即对一切 p∈P、q∈Q 有 pq = qp。
(5) 定义 φ: P × Q → G，φ(p,q) = pq。
   - 同态：φ((p1,q1)(p2,q2)) = φ(p1p2, q1q2) = p1p2q1q2；由 (4) 的 p2q1 = q1p2 得 = p1q1p2q2 = φ(p1,q1)φ(p2,q2)。
   - 满：由 (3) G = PQ，故每个 g ∈ G 可写成 pq。
   - 单：若 φ(p,q) = 1，则 pq = 1 ⇒ p = q^{-1} ∈ P ∩ Q = {1} ⇒ p = q = 1 即核平凡。
   故 φ 是同构，G ≅ P × Q。
(6) |Q| = 3 为素数，故 Q ≅ C_3，于是 G ≅ P × C_3。证毕。

推论：P ↦ P × C_3 是 32 阶群同构类到「96 阶、n_3 = n_2 = 1」的同构类的双射，故该格类数等于 g(32)。（数值 51 待核口径。）
