# 命题：对任意正整数 n，1^3+2^3+...+n^3 = (n(n+1)/2)^2

计划号：000000。两条**相互独立**的证明路径：(a) 归纳法；(b) 差分/telescoping。两条路径互不引用。

## 记号

对正整数 n，记 S(n) := 1^3 + 2^3 + ... + n^3。命题 P(n)：S(n) = (n(n+1)/2)^2。

## 路径 (a)：数学归纳法

**基始 n = 1。** 左边 S(1) = 1^3 = 1。右边 (1·(1+1)/2)^2 = (2/2)^2 = 1^2 = 1。两边相等，P(1) 成立。

**归纳步。** 设对某个正整数 n 有 P(n)，即

    S(n) = (n(n+1)/2)^2 。                                    (H)

证明 P(n+1)，即 S(n+1) = ((n+1)(n+2)/2)^2。

第 1 步（拆出末项）：由定义 S(n+1) = S(n) + (n+1)^3。代入 (H)：

    S(n+1) = (n(n+1)/2)^2 + (n+1)^3 。

第 2 步（通分到分母 4）：(n(n+1)/2)^2 = n^2(n+1)^2/4，而 (n+1)^3 = 4(n+1)^3/4。故

    S(n+1) = [ n^2(n+1)^2 + 4(n+1)^3 ] / 4 。

第 3 步（提取公因子 (n+1)^2）：两项都含 (n+1)^2，

    n^2(n+1)^2 + 4(n+1)^3 = (n+1)^2 [ n^2 + 4(n+1) ] 。

于是

    S(n+1) = (n+1)^2 [ n^2 + 4(n+1) ] / 4 。

第 4 步（展开方括号）：n^2 + 4(n+1) = n^2 + 4n + 4 = (n+2)^2（直接展开 (n+2)^2 = n^2+4n+4 核对）。

第 5 步（配方）：代入得

    S(n+1) = (n+1)^2 (n+2)^2 / 4 = [ (n+1)(n+2)/2 ]^2 ，

末一等号用到 (ab)^2 = a^2 b^2 与 4 = 2^2。这正是 P(n+1)。

**结论（路径 a）。** 由基始 P(1) 与归纳步（对一切正整数 n，P(n) ⇒ P(n+1)），由数学归纳法原理，P(n) 对一切正整数 n 成立。∎

## 路径 (b)：差分 / telescoping

**引理 L。** 对每个正整数 k，

    k^3 = (k(k+1)/2)^2 - ((k-1)k/2)^2 。                       (L)

*引理 L 的验证（纯代数，不引用路径 (a) 的任何内容）。* 右边通分到分母 4：

    (k(k+1)/2)^2 - ((k-1)k/2)^2
      = [ k^2(k+1)^2 - k^2(k-1)^2 ] / 4
      = k^2 [ (k+1)^2 - (k-1)^2 ] / 4 。

方括号内：(k+1)^2 = k^2 + 2k + 1，(k-1)^2 = k^2 - 2k + 1，相减得 (k^2+2k+1) - (k^2-2k+1) = 4k。故

    右边 = k^2 · 4k / 4 = k^3 ，

即 (L) 成立。∎

**求和（telescoping）。** 由 (L)，对任意正整数 n，

    S(n) = sum_{k=1}^{n} k^3 = sum_{k=1}^{n} [ (k(k+1)/2)^2 - ((k-1)k/2)^2 ] 。

把和拆成两个和：sum_{k=1}^{n} (k(k+1)/2)^2 - sum_{k=1}^{n} ((k-1)k/2)^2。令 a_k := (k(k+1)/2)^2（k ≥ 0），其中 a_0 := (0·1/2)^2 = 0；注意 ((k-1)k/2)^2 = a_{k-1}，于是 (L) 恰是 k^3 = a_k - a_{k-1}。于是

    sum_{k=1}^{n} k^3 = sum_{k=1}^{n} (a_k - a_{k-1}) = a_n - a_0 ，

最后一步是裂项相消：a_1,...,a_{n-1} 每个各出现一次正号一次负号而相消。由 a_n = (n(n+1)/2)^2 与 a_0 = 0，得

    S(n) = (n(n+1)/2)^2 - 0 = (n(n+1)/2)^2 ，

这正是 P(n)。∎（路径 b 对一切正整数 n 一次给出，不依赖归纳假设，也不引用路径 (a) 的任何一步。）

## 两条路径的关系

两条路径只共享命题本身与初等代数事实（平方展开、通分、裂项），互相不引用对方的一步；路径 (b) 不需要归纳假设，路径 (a) 不需要引理 L。
